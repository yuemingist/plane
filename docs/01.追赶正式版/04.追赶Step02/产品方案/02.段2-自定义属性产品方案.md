# 02. 段 2 产品方案 — 自定义属性核心

> 状态：已确认（段 2 实现依据）｜2026-11-16｜依据 [00.子项目章程](../项目管理/00.子项目章程.md) §3 段 2、[57.工作项类型与自定义属性/对比.md](../../01.功能调研/57.工作项类型与自定义属性/对比.md)（D-03/D-04/D-11，下称「57 号」）、[18-01 数据模型草案](../../01.功能调研/18.数据模型与API规格草案/01.工作项类型与自定义属性.md)、[P2-方案级汇总](../../01.功能调研/16.改造切入点/P2-方案级汇总.md) P2-13。
> 对标基准：57 号 §3.3 流程步骤表（8 类逐类实测）、§4.2 字段清单、§4.3 关键文案；云端截图在 57 号 assets/。
> 口径标注：〔实测〕= 57 号云端实测；〔设计决策〕= CE 侧自行定义（云端不可考处，编码与验收以此为准）。

## 1. 目标与非目标

### 1.1 目标（本段交付）

1. 属性 tab 从空态改为**可管理**：项目属性池（创建/编辑/删除/启停），列表列=名称｜状态｜类型｜使用中的工作项类型（计数）｜菜单。
2. 8 类属性及各自子配置（逐类见 §2）。
3. 绑定到工作项类型：类型详情页「+ 添加属性」→ 菜单「创建新属性 / 添加现有属性」；添加现有属性为多选弹窗（57 号 §3.4 步骤 2〔实测〕）。
4. 双门控：属性创建默认「已禁用」；启用需二次确认（57 号 §3.4 步骤 4 确认弹窗〔实测〕）。
5. 启停与删除约束（§4）。
6. 工作项详情侧栏「自定义属性」分区 + 新建弹窗属性字段，可读写已绑定且已启用的属性值（57 号 §3.4 步骤 7/8〔实测〕）。
7. 空态「即将支持」不再是主路径：属性 tab 直接渲染管理列表；空数据时渲染 57 号空态文案（「创建和自定义独特属性」+「未添加自定义属性：定义属性以跟踪工作项类型的特定数据。」）。类型详情页属性区同理。

### 1.2 非目标（本段明确不做）

- 列表列显示/按自定义属性筛选/导出（段 4「属性贯穿」）。
- 类型切换（D-07）、列表类型列（D-09）、Type/Parent type 筛选（已属 Step01/段 4）。
- 富文本属性的完整富文本编辑器：详情侧栏用多行文本编辑（textarea），新建弹窗同——57 号未实测富文本值的编辑控件形态（§8 待验证 3/8 均未覆盖），不臆造复杂交互〔设计决策，段 4 复核〕。
- FORMULA/CASCADING 属性类型（SDK 有、UI 无，18-01 §6）。
- workspace 级属性池（云端 v2 有两组路径，CE 项目语境单层即可，18-01 §4）。
- 属性值的必填强制校验闭环：`is_required` 字段落库与透出，但创建/编辑工作项时不做硬校验（57 号 §8 待验证 8：云端表现未实测）〔设计决策〕。

## 2. 8 类属性与子配置（逐类，锚点=57 号 §4.2〔实测〕）

创建弹窗公共字段：标题\*（display_name）、描述、属性类型\*（8 选 1 下拉）、底部「活动」「必填属性」复选框（**默认都不勾** → 新属性默认已禁用）＋取消/创建〔实测〕。编辑弹窗同表单，无类型绑定字段〔实测〕。

| 类型              | 枚举值      | 子配置                                                                                                                                             | 存储（settings JSON）                                                                              |
| ----------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| 文本 TEXT         | `text`      | 属性\*：单行 single-line（默认）/段落 multi-line/只读 readonly〔实测〕                                                                             | `{"display_format": "single-line"}`                                                                |
| 数字 DECIMAL      | `decimal`   | 格式：标准 standard（默认）/百分比 percent/货币 currency；小数位数（默认 2）；千位分隔符勾选（「显示 1,000 而不是 1000」）；默认值（可选）〔实测〕 | `{"format": "standard", "decimal_places": 2, "thousands_separator": false, "default_value": null}` |
| 下拉菜单 OPTION   | `option`    | 属性：单选 single_select（默认）/多选 multi_select；选项（回车成 chip，**至少 1 项**）；默认值（可选，从选项中选）〔实测〕                         | `{"is_multi": false, "options": [{"id","name","is_default"}]}`                                     |
| 布尔值 BOOLEAN    | `boolean`   | 无额外配置〔实测〕                                                                                                                                 | `{}`                                                                                               |
| 日期 DATE         | `date`      | 无额外配置〔实测〕（18-01 有 display_format 枚举，云端 UI 未见表单项，不实现）                                                                     | `{}`                                                                                               |
| 成员选择器 MEMBER | `member`    | 属性：单选（默认）/多选；默认值（可选，选成员）〔实测〕                                                                                            | `{"is_multi": false, "default_value": null}`                                                       |
| 富文本 RICH_TEXT  | `rich_text` | 无额外配置〔实测〕                                                                                                                                 | `{}`                                                                                               |
| URL URL           | `url`       | 无额外配置〔实测〕                                                                                                                                 | `{}`                                                                                               |

> 「多选」在下拉/成员两类的子配置内实现，不是独立类型〔实测 57 号 §3.3 3c/3f〕。下拉选项以 `settings.options` JSON 数组承载（每项含稳定 `id` 供值引用），不另立选项表——CE 侧 3 表设计见技术方案（选项级元数据如描述/图标云端 UI 未实测，不需要独立表）。

## 3. 用户可感知行为与流程

### 3.1 属性池（属性 tab）

- 列表列：名称｜状态（活动=绿/已禁用=灰）｜类型（带图标 badge）｜使用中的工作项类型（计数）｜…菜单（编辑/删除）〔实测 57 号 §1.2 Tab2〕。
- 「添加新属性」为 split-button（主按钮+下拉箭头）〔实测〕：CE 本段主按钮直接打开创建弹窗，下拉箭头不做（展开内容未取证，57 号 §8 待验证 4）〔设计决策〕。
- 启停入口：属性行菜单编辑弹窗内「活动」复选框（57 号 §3.3 步骤 5 行菜单仅 编辑/删除〔实测〕；CE 补一行内状态 badge，不做独立启停菜单项）。

### 3.2 绑定流（类型详情页）

1. 类型 tab 点行 → 类型详情页（Step01 已建路由）：启停 toggle + 属性区。
2. 属性区 = 「自定义属性」列表 + 「+ 添加属性」→ 菜单：创建新属性 / 添加现有属性〔实测〕。
3. 添加现有属性弹窗：搜索框 + 属性行（复选框+状态 badge+类型 badge）+ 取消/添加（未选时禁用），多选〔实测〕。
4. 绑定后：类型详情属性列表出现该属性，badge=「已禁用」（属性池级 is_active）〔实测〕。
5. 行菜单「启用属性」→ 确认弹窗：「启用此属性？此属性将在所有已关联的工作项类型中启用。每种类型将根据其上下文显示选项，如果未配置任何选项，则显示默认选项。」取消/启用〔实测〕。
6. 行菜单「移除」→ 解绑（不影响属性池与其他类型绑定）〔设计决策：云端解绑语义未实测，按最小侵入取解绑只删桥不删值〕。

### 3.3 工作项读写

- 详情侧栏：「自定义属性」分区，仅当工作项类型绑定了**已启用**属性时出现；控件按属性类型渲染（§5）。值为空显示占位（添加文本/选择日期/选择选项…）〔实测 57 号 §3.4 步骤 8〕。
- 新建弹窗：按所选类型渲染绑定且已启用的属性字段（默认类型无属性则不渲染分区）〔实测 57 号 §3.4 步骤 12 形态〕。
- 值变更留活动痕为段 4 面（云端 `set X to "值"` 文案已录，本段先落 API 幂等写，活动留痕不阻塞本段验收）〔设计决策〕。

## 4. 启停与删除约束矩阵

| 操作     | 条件                       | 行为                                                  | 依据                                                                  |
| -------- | -------------------------- | ----------------------------------------------------- | --------------------------------------------------------------------- |
| 创建属性 | —                          | is_active=false（已禁用），需手动启用                 | 57 号 §3.3 步骤 4〔实测〕                                             |
| 启用属性 | 已绑定到 ≥1 类型           | 二次确认弹窗 → is_active=true                         | 57 号 §3.4 步骤 4〔实测〕                                             |
| 禁用属性 | —                          | is_active=false；已存的值保留不删，界面不再显示该属性 | 〔设计决策：云端未实测禁用路径，取保守口径〕                          |
| 删除属性 | **未被任何类型绑定**       | 删除属性行 + 级联删除其属性值                         | 〔设计决策〕                                                          |
| 删除属性 | **被类型绑定（使用中）**   | 拒绝 400，提示先在类型详情移除绑定                    | 57 号 §1.2「使用中的工作项类型」列语义 + 默认类型保护先例〔设计决策〕 |
| 解绑     | —                          | 删除绑定桥；已存值保留（属性可能绑定到其他类型）      | 〔设计决策〕                                                          |
| 下拉选项 | 选项数 ≥1                  | 选项集非空校验，否则 400                              | 57 号 §4.2「选项（回车添加 chip）」+ 技术方案校验面                   |
| 重名属性 | 项目池内同名（同类型不限） | 拒绝 400                                              | 对齐 Step01 类型重名约束〔设计决策〕                                  |

## 6. 权限与门控

- 属性池/绑定/值写：ADMIN/MEMBER；读：ADMIN/MEMBER/GUEST（对齐 Step01 §2.3，Guest 只读）。
- 门控：全部属性端点要求项目已启用工作项类型（`Project.is_issue_type_enabled`）——属性体系挂在工作结构特性下，未启用项目 403〔设计决策，沿用 Step01 门控 mixin〕。
- 值读取：工作项详情可见者即可读（Guest 可读）；值写入与工作项编辑权限一致（ADMIN/MEMBER）。

## 7. 验收用例（GWT，≥15 条，正/拒路径）

正向：

1. Given 项目已启用工作项类型，When 属性 tab 打开，Then 显示属性池列表（空态文案与 57 号一致）与「添加新属性」按钮。
2. Given 创建弹窗选「文本」，When 填标题+单行+不勾活动，Then 创建成功且状态=已禁用、使用中的工作项类型=0。
3. Given 创建弹窗选「数字」，When 格式=货币+小数位 0+千位分隔符，Then settings 落库且编辑弹窗回显。
4. Given 创建弹窗选「下拉」且添加 2 个选项，Then 创建成功；When 选项为空提交，Then 400 拒绝（拒）。
5. Given 创建弹窗选「成员」+多选，Then settings.is_multi=true。
6. Given 类型详情页「+ 添加属性」→「添加现有属性」，When 勾选 2 个属性并添加，Then 类型属性列表出现 2 行（均已禁用 badge）且属性池「使用中」计数 +1。
7. Given 已绑定属性，When 行菜单「启用属性」并确认，Then 状态变「活动」（双门控第二门）。
8. Given 属性已启用且绑定到工作项类型，When 打开该类型工作项详情，Then 侧栏出现「自定义属性」分区并可填写保存。
9. Given 下拉属性（单选），When 详情侧栏选择选项 B，Then 刷新后值保持为选项 B。
10. Given 成员多选属性，When 选择 2 名成员，Then 值以数组保存并回显 2 chips。
11. Given 新建弹窗选择了有绑定属性的类型，When 展开属性区，Then 出现对应属性字段并随工作项一起保存。
12. Given 属性未被绑定，When 属性池删除该属性，Then 删除成功且其属性值级联清除。

拒绝/约束：

13. Given 属性已绑定到任一类型，When 属性池删除该属性，Then 400 并提示先移除绑定（拒）。
14. Given 项目未启用工作项类型，When 调属性池 API，Then 403（拒）。
15. Given Guest 角色，When 写属性/绑定/值，Then 403；When 读，Then 200（拒/读分离）。
16. Given 下拉属性已启用，When 提交不属于选项集的值，Then 400（拒）。
17. Given URL 属性，When 提交非法 URL（如 `not a url`），Then 400（拒）。
18. Given 属性已禁用（未启用），When 该类型工作项详情加载，Then 不显示该属性（双门控第一门生效）。
19. Given 类型 A、B 均绑定属性 P 且 P 已启用，When 解绑 A，Then B 仍显示 P 且值保留。
20. Given 跨项目属性，When 用项目 B 的上下文读写项目 A 的属性，Then 404/403（隔离）。

## 8. 假设与云端不可考处登记

| #   | 假设/决策                                             | 依据                                                             | 若错误的后果                              |
| --- | ----------------------------------------------------- | ---------------------------------------------------------------- | ----------------------------------------- |
| A1  | 下拉选项存 settings JSON 而非独立表                   | 云端 UI 仅名称+默认值语义，选项级元数据未实测                    | 官方 schema 若独立表，段 4 用收敛迁移搬迁 |
| A2  | 解绑=只删桥，值保留                                   | 云端类型切换警告「已删除属性的值将添加到描述中」暗示值不随绑定删 | 若云端解绑即删值，补级联删除              |
| A3  | 属性删除=级联删值                                     | 删除语义直觉；云端未实测                                         | 可恢复（值可重建）                        |
| A4  | 禁用属性保留已存值                                    | 对齐类型禁用保留数据先例（Step01）                               | 影响小（隐藏即可）                        |
| A5  | 富文本编辑用多行文本域                                | 云端编辑控件未实测                                               | 段 4 换 @plane/editor 不动 schema         |
| A6  | 属性启用入口在类型详情行菜单（池 tab 无独立启停菜单） | 57 号 §3.3 步骤 5 行菜单仅编辑/删除                              | 文案级差异                                |
| A7  | is_required 落库不做硬校验                            | 57 号 §8-8 未实测                                                | 补校验为增量改动                          |
