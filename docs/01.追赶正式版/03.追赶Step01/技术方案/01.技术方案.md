### 2.2 启用动作（自动建 Epic + Task）〔已确认规则，代码为推断形态〕

`IssueTypeEnableEndpoint`（或 ViewSet 的 `enable` action）在 `transaction.atomic()` 内：

```python
# 伪代码（apps/api/plane/app/views/issue_type.py，编码时落盘）
def enable(self, request, slug, project_id):
    project = Project.objects.get(pk=project_id, workspace__slug=slug)
    if project.is_issue_type_enabled:
        return 400
    with transaction.atomic():
        # 锁行防并发双开
        project = Project.objects.select_for_update().get(pk=project_id)
        epic = IssueType.objects.create(workspace=project.workspace, name="Epic",
                                        is_epic=True, is_active=True, level=1,
                                        logo_props={"in_app_icon": {"color": "#fcbe53", "name": "mountain"}})
        task = IssueType.objects.create(workspace=project.workspace, name="Task",
                                        is_epic=False, is_active=True, level=0)
        ProjectIssueType.objects.create(project=project, issue_type=epic, level=1, is_default=False)
        ProjectIssueType.objects.create(project=project, issue_type=task, level=0, is_default=True)
        project.is_issue_type_enabled = True
        project.save(update_fields=["is_issue_type_enabled"])
    return 200
```

- 字段细节按 57 号 §3.1 步骤 3 复刻：Epic（活动/level 1/山形图标）、Task（活动/默认/level 0）。图标色值以 `cloud-work-item-types-enabled-types-tab` 截图对照为准〔推断〕。
- **与官方 seed 不完全一致的收敛预案**（P0-4 §9.2、产品方案 §3.2-4）：升级官方时若官方 CE 版自带 enable 种子，按 `(workspace, name, is_epic)` 幂等去重脚本收敛 level/is_default/logo_props；本步 enable 幂等（已启用 400）保证不会重复建。
- `IssueType.is_default`（workspace 级默认）本步**不消费**：项目内默认以 `ProjectIssueType.is_default` 为准（18-01 §1.1、云端 mark-default 为 workspace 级 op，但本步 UI 只有项目语境，不引入工作区默认语义）——写在 serializer 文档字符串防后人误用。

### 2.3 权限与门控〔已确认〕

- 装饰器沿用 `apps/api/plane/app/permissions/base.py:19` `allow_permission`（ROLE.ADMIN=20/MEMBER=15/GUEST=5）：写接口 `[ADMIN, MEMBER]`，读接口 `[ADMIN, MEMBER, GUEST]`（Guest 只读，章程验收 8 后半句；参照 `app/views/state/base.py:23` 的三角色读模式）。
- 开关门控：ViewSet `initial()` 或 `get_queryset()` 前置校验 `project.is_issue_type_enabled`：
  - 未启用 + GET 列表/详情 → `403 {"error": "Work item types are not enabled for this project"}`（章程验收 8 允许 403/400；门卡页面不依赖此 GET 成功——前端用 project store 的 flag 直接渲染门卡，§3.2）。
