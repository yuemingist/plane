## 1. 目标与非目标

## 2. 状态页核对（段 0）

对照正式版与开源版状态页：状态组、新建/编辑、设默认、删除约束、行菜单、文案。列出「已对齐」与「待补差异」。无差异则写核对结论即可。

## 3. 类型启用与管理页（段 1a）

- 入口：项目设置 → 工作结构 → 工作项类型（含未启用门卡、启用确认警告文案）。
- 类型 tab：表格列、搜索/筛选/排序、添加类型、行菜单、默认类型不可删、新类型默认已禁用。
- 类型详情页：启停、与属性的关系（本步不实现绑定，只说明入口如何处理）。
- 层级 tab：只读可视化规则（Epic=1，其他=0）；写明「本步不做层级编辑」。
- 启用后自动创建 Epic + Task 的规则与默认字段。

## 4. 工作项贯穿（段 1b）

详情 chip 与切换（确认弹窗文案、活动留痕）；新建弹窗的类型选择；列表显示属性中的类型列；筛选 Type / Parent type。明确**不做**自定义属性筛选与属性值渲染。

## 5. Epic 作为类型的产品规则

Epic 布局入口何时出现；子工作项类型下拉如何排除父链上位类型。
