## 2. 官方变更要点

1. **前端全面重写**：Propel 设计系统（UI primitives 来自 `@makeplane/propel`）+ React 19 + React Router 8 + Tiptap/Hocuspocus v3。Web/Space/Admin 全新界面。
2. **部署形态**：admin/web 镜像 nginx→Caddy；镜像按架构原生构建；PostHog 移除；API 依赖改 uv 管理（本仓库 AGENTS.md 已是 uv 流程）。
3. **数据库**：仅 3 个官方迁移（0123-0125 尾部），无破坏性 schema 变更。
4. **安全修复（自托管必须升级的理由）**：HTTP 动词/action 越权（可夺 workspace）、租户隔离大批修复、live 协作每次连接验权+guest 只读、guest 限制扩面、issue 系统字段只读、OAuth/cookie/限流/注入防护、rediss 证书验证。
5. **External API**：guest_view_all_features 强制、created_by/created_at 不再信任、子资源 404 化。
6. 升级注意：Redis TLS 默认验证、跨域写入 Origin 限制（dev server 形态需确认 CORS/CSRF 信任源——**对 mini dev 部署是直接相关项**）、MinIO 模板凭据警告。

## 3. 对 Step01 / Step02 的主要冲击（预判，盘点详见技术方案）

- **A 后端**：迁移零撞号（官方止 0125，我们 0126-0129 顺序在后）；models/views 冲突集中在 issue 相关安全修复文件（issue serializer/viewset/base 与我们 type_id/property 改动同文件——需逐个合并）；外部 API v1 不涉及。
- **B 机械前端**：路由注册（core.ts）、常量、types、i18n 键——RR8 迁移后路由结构可能变化，需按新结构重挂。
- **C 设计系统 UI**：Step01/02 全部设置页组件（类型/属性/工作流/状态）、详情侧栏分区、新建弹窗、筛选 chip——旧体系组件在 Propel 重写下大概率冲突或失效，**按新组件重做**而非硬合。
- **特别关注**：issue PATCH 校验挂载点（段 3/5 的 validate 在 `IssueViewSet.partial_update`——官方安全修复大改 view 层，挂载点需重新定位）；`IssueListEndpoint.values()`（BUG-08 相关 grouper/values 链路）。
