## 5. 发现的错位/缺陷与待复核清单（供次日 gpt-6-astra 事后复核）

按严重度排序，均非阻塞：

1. **[待复核/疑似一次性] Type 筛选值下拉首开串位**：第一次从 rich filters 菜单点 Type 后，值下拉搜索框占位符显示「Search labels...」，选项为 Bug/Feature/Enhancement/Documentation（疑似标签数据）；重开该下拉后选项恢复为正确的 Task/Bug/Epic/Feature。未能稳定复现，建议复核 Type 芯片值下拉的数据源挂接（截图 `ce-sync-06-filter-type-bug`）。
2. **[口径确认] 自定义属性写值的保存时机**：侧栏文本框在输入过程中不触发保存（捕获不到请求），失焦后触发；首次自动化写入（合成 input 事件＋失焦）曾出现「界面显示已写、刷新后为空」的中间态，随后确认最终落库与回显一致。真实人工输入路径为：输入 → 失焦 → 保存。建议复核是否与 Step02 段 2 验收时的防抖/保存时机口径一致。
3. **[入口形态变化记录] 导出入口**：v1.5.0 新 UI 的工作项列表工具栏无「导出」按钮，入口在工作区设置 → 导出。Step02 段 4 记录的入口形态（若当时为列表内）需在新 UI 下更新测试口径文档。
4. **[轻微错位记录] 导出文件名时区**：Nov 18（本地 CST）创建的导出，其文件名为 `export-demo-workspace-562c21-2026-11-17.zip`（UTC 日期）；Exported On 显示本地日期。非缺陷，建议留意后续对账。
5. **[环境] IAB 截图面故障**：ZCode 内置浏览器截图接口全程超时（surface preparation timeout），本次全部截图走 CDP 兜底（Chrome for Testing 151 headless）。环境问题，与被测系统无关。
6. **[现场变化留痕]**：本日操作在 Default Workflow 变更历史新增 2 条「更新了流转规则」（配规则+清规则各一条）；导出历史新增 1 条 Nov 18 CSV 记录。均为测试动作的自然痕迹，无需清理。
