# 项目设置 对比（实测日期 2026-11-14）

> 云端：GZRC 项目设置（/yueming/settings/projects/{id}/...）
> CE：demo-workspace / WEB 项目设置（/demo-workspace/settings/projects/{id}/...）

## 页面结构对比（云端 vs CE）

### 设置导航（侧栏分组）

| 分组     | 云端                                                                                                         | CE                                                         |
| -------- | ------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------- |
| 常规     | 常规、成员、**工作日志(Worklogs)**                                                                           | 常规、成员                                                 |
| 功能     | 周期、模块、视图、页面、Intake、**时间跟踪**、**里程碑**、**项目更新**、**发布(Releases)**、**记忆(Memory)** | 周期、模块、视图、页面、接收(Intake)。**无工作项类型开关** |
| 工作结构 | **工作项类型**（类型管理页）、状态、**工作流(Workflows)**、标签、估算、**模板(Templates)**                   | 状态、标签、估算                                           |
| 自动化   | 自动化、**重复工作项(Recurring)**                                                                            | 自动化                                                     |

### 常规页

- 两版同构：封面、项目名称、描述、Project ID、网络(公开/私有)、项目时区、更新按钮、归档区。CE 额外无差异要点。

### 功能设置页形态

- 云端周期页：启用开关 + **并行周期(Upgrade)** + 自动安排周期 + **手动周期推进(Upgrade)**。
- 云端里程碑页：启用里程碑开关（无更多配置）。
- CE 功能页（周期等）：单开关形态（未逐一截图，导航结构一致、无付费项）。

### Intake 设置页

| 区域     | 云端                                                                               | CE                   |
| -------- | ---------------------------------------------------------------------------------- | -------------------- |
| 启用开关 | 启用 Intake                                                                        | 启用接收（命名差异） |
| 接收责任 | **通知负责人**（默认受理人下拉）                                                   | 无                   |
| 接收来源 | **应用内**、**电子邮件**（项目邮箱收请求）、**表单**（公开表单给工作区外人员提交） | 无（仅开关）         |

### 工作项类型（U2）

|            | 云端                                                                                                                                                                               | CE                                                                                                                                                    |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 设置入口   | 工作结构 → 工作项类型                                                                                                                                                              | **无**（导航无此项；/work-item-types/ 与 /features/issue-types/ 路由均 404）                                                                          |
| 管理页形态 | 三 tab：**工作项类型 / 属性 / 层级**；类型表格（图标+名称+默认标记、地位=活动、特性引用数、...菜单）；搜索/筛选/排序/添加工作项类型按钮。GZRC 现有 Epic、需求(默认)、Task 三个类型 | 无管理页。数据层仍支持类型（工作项有类型图标、列表/详情展示、活动记录），但无创建/编辑/删除 UI（源码 grep 无 issue-type 管理服务/路由，仅展示层引用） |

### 自动化页

| 区域         | 云端                                                                                            | CE                                     |
| ------------ | ----------------------------------------------------------------------------------------------- | -------------------------------------- |
| 预置自动化   | 自动归档已关闭的工作项、自动关闭工作项、**自动提醒**（到期前邮件+应用内提醒受理人）             | 自动归档已关闭的工作项、自动关闭工作项 |
| 自定义自动化 | **有**："自定义自动化"区 + 空态（触发器/条件/操作）+ 创建自动化按钮；另有"重复工作项"独立设置页 | 无                                     |

### 成员 / 控制等

- CE 成员页与云端成员页同构（角色管理）；CE 无"控制/控制面板"类项目级入口（云端的 Intake 权限、访客控制等在成员/角色里）。云端设置顶部有**搜索设置**框（CE 无）。

## 差异点清单

| 编号      | 差异                      | 云端形态                                                      | CE 形态                               | 影响                                       | 难度                                             |
| --------- | ------------------------- | ------------------------------------------------------------- | ------------------------------------- | ------------------------------------------ | ------------------------------------------------ |
| D-01-设置 | 工作项类型管理            | 独立设置页（类型/属性/层级 三 tab，默认类型、特性引用）       | 无入口无页面（U2 成立）；数据模型残留 | 类型体系只能靠 API/造数维护                | M（后端模型已在，补 UI 即可）                    |
| D-02-设置 | 功能开关广度              | 周期/模块/视图/页面/Intake/时间跟踪/里程碑/项目更新/发布/记忆 | 周期/模块/视图/页面/接收              | 缺 5+ 功能模块                             | 按模块各自计（时间跟踪/发布/记忆 L，项目更新 M） |
| D-03-设置 | 工作流(Workflows)设置     | 状态之外独立"工作流"页                                        | 无                                    | 状态流转规则配置                           | M                                                |
| D-04-设置 | 模板(Templates)           | 工作结构含模板页（工作项模板）                                | 无                                    | 模板体系（新建弹窗的模板按钮也是云端独有） | M                                                |
| D-05-设置 | 自定义自动化 + 重复工作项 | 触发器/条件/操作构建器 + 重复工作项设置                       | 仅自动归档/自动关闭两个开关           | 自动化能力差距大                           | XL                                               |
| D-06-设置 | 自动提醒                  | 到期前提醒（邮件/应用内）                                     | 无                                    | 通知类                                     | M                                                |
| D-07-设置 | Worklogs 工作日志         | 常规分组含工作日志                                            | 无                                    | 时间记录功能                               | L                                                |
| D-08-设置 | Intake 来源               | 应用内/电子邮件/公开表单 + 默认受理人通知                     | 仅启用开关                            | 外部请求渠道（邮件/表单需基础设施）        | L（表单 M）                                      |
| D-09-设置 | 设置搜索框                | 侧栏顶部"搜索设置"                                            | 无                                    | 小体验                                     | S                                                |
| D-10-设置 | Intake 命名               | Intake                                                        | 接收                                  | 术语统一                                   | S                                                |

## 待验证问题闭环

- **U2（Features 里 Issue Types 开关与类型管理页）**：**成立——CE 不存在**。CE 设置功能组只有 周期/模块/视图/页面/接收，无 Issue Types 开关；/work-item-types/、/features/issue-types/ 路由 404；源码无管理页/服务（仅展示层引用 issue_type）。云端有完整"工作项类型"管理页（类型列表+属性+层级 tab，见 cloud-project-settings-work-item-types 截图）。CE 数据中 WEB 的 Epic/Bug/Feature 类型为造数直插，UI 无法管理。
