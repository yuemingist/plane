### 1.2 通知触发实测（自我触发行为）

| 触发方式                                     | 是否产生新通知                                                                                                                    | 证据                                                                             |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 给自己指派工作项（SURVEY-1 添加负责人=自己） | **否**                                                                                                                            | 活动流出现「added a new assignee yueming0624.」但收件箱未新增（仍为 2 条旧通知） |
| 评论中提及自己（@yueming0624 mention 芯片）  | **否**                                                                                                                            | 评论成功发布，收件箱「全部」仍为 2（旧自动化通知），「提及」tab 空               |
| 自动化指派他人→自己（前批测试遗留）          | **是**                                                                                                                            | 两条通知「调研-自动化触发C/B」=「Automation added assignee yueming0624.」        |
| 结论                                         | **triggered_by == receiver 的通知被抑制**（防自我打扰）；需要第二人触发才能产生提及/评论/指派通知。单账号无法实测完整通知内容矩阵 | —                                                                                |
