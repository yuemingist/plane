# 全局搜索与命令面板 对比（实测日期 2026-11-14）

> 实测方式：CE 在 `/demo-workspace` 首页点击顶栏 "Search commands..."（Cmd+K 等价入口）；云端在 app.plane.so 首页点击顶栏 Search。

## 页面结构对比（云端 vs CE）

### 命令面板（CE）vs 搜索弹窗（云端）

| 结构       | 云端                                                                                                                   | CE                                                                                 |
| ---------- | ---------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 入口       | 顶栏 Search 输入框（点击/输入即用）                                                                                    | 顶栏 "Search commands..." 输入框 + Cmd+K                                           |
| 空态内容   | 仅标题 "Search your workspace" + 副标题 "Start typing to search across work items, projects, cycles, modules and more" | **完整命令列表**：创建 / 导航 / 账号 / 其他 / 偏好设置 / 帮助 六组                 |
| 实体筛选   | 输入后出现 chips：全部/项目/工作项/周期/模块/视图/页面/团队空间/评论                                                   | 无 chips；结果按类型分组（Work items 等）                                          |
| 结果区     | 搜索结果列表 + **"Go to advanced search page"** 入口                                                                   | 结果列表（如 "Search results for 'dark mode' in workspace: → Work items → WEB-5"） |
| 底部       | 关闭按钮                                                                                                               | "工作区级别" 开关（限制搜索范围）                                                  |
| 快捷键提示 | 无                                                                                                                     | 每项右侧显示序列键（N→I、G→H、O→P 等）                                             |

### CE 命令面板命令全集（实测）

- 创建：新建工作项 (N I)、新建项目 (N P)、新建工作区
- 导航：打开项目 (O P)、打开工作区设置 (O S)、打开工作区 (O W)、转到主页 (G H)、转到收件箱 (G X)、转到我的工作 (G Y)、转到所有工作项、转到已分配工作项、转到已创建工作项、转到已订阅工作项、转到工作区分析 (G A)、转到工作区设置 (G S)、转到工作区草稿 (G J)、转到工作区归档 (G R)、转到项目列表 (G P)、转到账号设置
- 账号：工作区邀请、退出登录
- 其他：切换应用侧边栏 (⌘B)、复制当前页面 URL (⌘⇧C)、聚焦搜索输入框 (⌘F)
- 偏好设置：更改界面主题、更改时区、更改一周的第一天、**更改界面语言**
- 帮助：打开键盘快捷键 (⌘/)、打开 Plane 文档、加入我们的论坛、报告 Bug

### 云端搜索弹窗/结果页

- 弹窗：输入后显示实体 chips（全部/项目/工作项/周期/模块/视图/页面/团队空间/评论，比 CE 分组维度更细：含周期/模块/视图/页面/团队空间/评论独立分类）。
- 高级搜索页 `/yueming/search/?q=...`：全宽搜索条 + 同一组 chips + 结果列表；空态 "没有匹配的结果 / 移除搜索条件以查看所有结果"。
- CE **没有独立高级搜索页**，搜索完全收敛在命令面板弹层内。

### 设置内搜索

- 云端：工作区设置侧边栏顶部有 "搜索设置" 搜索框（可过滤设置项）。
- CE：工作区设置侧边栏无搜索框（侧边栏本身也短得多）。

## 差异点清单

| 编号      | 云端形态                                                               | CE 形态                                                 | 影响                                                                                     | 追赶难度 |
| --------- | ---------------------------------------------------------------------- | ------------------------------------------------------- | ---------------------------------------------------------------------------------------- | -------- |
| D-01-搜索 | 空态仅引导输入，无命令列表                                             | CE 面板空态即全量命令清单（6 组，含序列键提示）         | CE 反而更强；云端把命令性操作移到别处（AI/顶栏），搜索更纯粹。若追赶云端形态反而要做减法 | —        |

| D-04-搜索 | 设置侧边栏内置"搜索设置"                                               | 无                                                      | 设置项查找效率差异                                                                       | S        |
| D-05-搜索 | 搜索弹窗底部无范围开关                                                 | CE 有"工作区级别"开关（跨工作区搜索入口，trial 下禁用） | 云端为单工作区架构无需此开关；CE 保留多工作区搜索                                        | —        |
| D-06-搜索 | 搜索弹窗右上出现筛选图标（高级过滤）                                   | 无                                                      | 云端搜索附加过滤能力                                                                     | M        |

## 待验证问题闭环

- Cmd+K 直接触发：CE 顶栏框有 "[active]" 聚焦态，点击即可打开；合成 Cmd+K 按键未能触发面板（CUA 组合键限制），以点击入口为准，两者行为等价（CE 源码定义了 Cmd+K 绑定）。
- 云端是否也有命令面板：云端搜索弹窗空态**没有命令清单**，表明云端新版把"命令"角色弱化（AI 时代导航靠 AI/首页）；其搜索弹窗承担纯搜索。此为产品形态差异而非能力缺失。
- CE 面板搜索实测：输入 "dark mode" 返回工作区内工作项 WEB-5，结果分组与跳转正常。
