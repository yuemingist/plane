# 企业能力与权限 对比（实测日期 2026-11-14）

> 云端：app.plane.so/thinkym（YM Research，Owner，**Business 试用版**徽标，试用至 2026-11-28）。
> CE：http://yuemingmac-mini.tail43aa97.ts.net:3000/demo-workspace（管理员账号 yueming@yuegr.com）。
> 结论速览：成员角色全集云端比 CE 多一个 **Owner**（邀请时可选 4 角色即含 Owner）；云端新增「工作空间治理 / 团队空间 / 身份(SAML·OIDC)」三个治理页；治理在 Business 试用下仍锁定（升级按钮）、SAML/OIDC 配置按钮禁用（Enterprise 档）；账号级安全两侧一致（均只有修改密码，无 2FA/会话管理）。

| Plane AI 分组    | 常规 / 智能体 / 记忆                                                                                                                                                            | 无                                              |

### 工作空间治理（/settings/governance，云端独有）

| 维度 | 云端 Business                                                                                                                                        |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 定位 | 「集中并标准化工作区中项目的配置方式」：工作区管理员在**工作区级别管理共享控件**（状态、工作流、自动化、模板等），项目只能导入使用、不能独立创建修改 |
| 开关 | 「启用治理」卡片：**此操作是永久性的且无法撤消**；按钮为「**升级**」——Business 试用下仍锁定，属更高档位（Enterprise）能力                            |
| 文档 | docs.plane.so/workspace-administration/workspace-governance                                                                                          |
| CE   | 路由 /settings/governance/ 直连 404（「Oops! Something went wrong」），侧边栏无入口                                                                  |

### 团队空间（/settings/teamspaces，云端独有）

| 维度 | 云端 Business                                                                                                              |
| ---- | -------------------------------------------------------------------------------------------------------------------------- |
| 定位 | 「团队空间将团队的工作集中到一处——关联其项目，并一起查看全部工作」；启用后「团队空间成员可以访问其团队空间关联的所有项目」 |
| 开关 | 「启用团队空间」switch，**Business 试用下可用**（默认关）                                                                  |

### 身份（/settings/identity，云端独有）——SAML/SCIM 档位核实

| 维度     | 云端 Business 试用                                                                        |
| -------- | ----------------------------------------------------------------------------------------- |
| 域名管理 | 「已验证的域名」卡片 + 「添加域名」按钮（**可点**，验证邮箱域名后可为该域名用户启用 SSO） |
| SAML     | 「启用 SAML」卡片 + 「配置」按钮 **disabled**（Enterprise 档，Business 试用不可用）       |
| OIDC     | 「启用 OIDC」卡片 + 「配置」按钮 **disabled**（同上）                                     |
| SCIM     | 页面无任何 SCIM 入口/字样（未随 Business 暴露）                                           |
| CE       | 无身份页：路由 404、侧边栏无入口；CE 代码亦无 SAML/SCIM（见 11.盘点 3.7）                 |

## 待验证问题闭环

- **SAML/SCIM 在 Business 下是否可见？** 已闭环：SAML/OIDC 卡片**可见但配置按钮 disabled**（Enterprise 档锁定）；SCIM 完全不可见。域名验证（SSO 前置）在 Business 下可用。证据：cloud-identity-saml-oidc-2026-11-14.png。
- **角色下拉全集是否超出 Admin/Member/Guest？** 已闭环：云端邀请下拉全集 = **Owner/Admin/Member/Guest**（4 个）；CE = Guest/Member/Admin（3 个）。Owner 在云端也可直接邀请授予。证据：cloud-role-dropdown / ce-role-dropdown。
- **云端有无治理/私有空间开关？** 已闭环：治理=永久开关（锁定需升级）；团队空间=可用开关（默认关）。「私有空间」未见独立概念（团队空间访问模型替代）。证据：cloud-governance / cloud-teamspaces。
