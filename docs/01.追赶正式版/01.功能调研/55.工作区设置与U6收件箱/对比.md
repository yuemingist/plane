# 工作区设置与U6收件箱 对比（实测日期 2026-11-14）

> 云端：app.plane.so/thinkym（Business 试用）。CE：yuemingmac-mini.tail43aa97.ts.net:3000/:3002。
> ⚠️ 采集说明：本批后半段浏览器截图表面多次超时（环境级故障），个别截图缺失处已注明，字段与流程均以 DOM 快照逐字记录为据。
> 结论速览：**U6 最终判定——CE 公开 intake 提交链路当前不可用**（space 前端无 intake 表单 UI + 发布链接页面崩溃 + 公开 intake API 401），但 **CE 登录态的 Inbox（Intake 页）分诊·接受流程完整可用**（待处理列表→接受→属性确认→成为正式工作项，活动流记录 "accepted this work item from intake"）；云端 Intake 三来源（应用内/电子邮件/公开表单）且公开表单免费一键启用（sites.plane.so/intake/<anchor>）。

## 补测遗留闭环

### 1）CE 工作项列表多选批量操作 UI

- **最终结论：当前 CE 不存在多选批量操作 UI（代码级硬关闭）。**
- 实测：表格布局（spreadsheet）行首无复选框列（a11y 树与 DOM 均无）；行首单元格内有复选框**空占位** `<div class="grid size-4 place-items-center"></div>`。
- 代码证据：`apps/web/hooks/use-bulk-operation-status.ts` = `export const useBulkOperationStatus = () => false;`（写死）；spreadsheet/list/gantt 布局均以 `disabled={!isBulkOperationsEnabled || isEpic}` 传给 MultipleSelectGroup；`MultipleSelectEntityAction` 在 `isSelectionDisabled` 时 `return null`。
- 影响：CE 无法批量改状态/优先级/删除等；云端有完整多选批量操作栏。
- 尝试过程记录：悬停行首（复选框为悬停显现设计）→ 占位 div 为空；键位 shift+click 无触发对象。

### 2）云端周期创建弹窗 Work item type 下拉

- **最终结论：当前云端 Business 版创建周期弹窗没有 Work item type 下拉。**
- 实测：项目 thinkym → 周期 → 添加周期 → 弹窗字段仅 **标题 / 描述 / 日期范围 / 取消·创建周期**（先弹「使用周期取得进展」引导卡，按 Q 快捷键提示）。
- 该下拉可能出现在其它入口（如项目级 Intake 表单创建或旧版本），当前版本不存在，如实记录。

### 3）云端工作区级 Views 页

- **最终结论：云端工作区级视图存在但路由为 `/thinkym/workspace-views/`**（侧边栏「更多」→ 视图）。
- 形态：系统自带 4 个视图（所有工作项/已分配/已创建/已订阅，均标「由 Plane 创建」）+ 添加视图按钮；视图行菜单仅 在新标签页中打开/复制链接/导出（**无发布**）。
- CE：`/demo-workspace/` 工作区级也有 Views（旧批次已对比）；CE 工作区扩展侧边栏（更多）同样有 视图/周期/分析/归档/仪表板 五项——与云端一致。
