# Space公开门户 对比（实测日期 2026-11-14）

> 云端：app.plane.so/thinkym（Business 试用）。实测了工作区级视图发布（不存在）与**项目页面发布**（免费可用，已实际发布并访问公开站）。
> CE：yuemingmac-mini.tail43aa97.ts.net（web :3000 / space :3002）。实测项目发布入口与弹窗、space 首页形态、页面行菜单（无发布项）。
> 结论速览：**云端页面发布免费可用**（发布页面→生成 sites.plane.so 公开 URL，无需确认付费）；云端工作区级视图无发布入口；CE 项目发布弹窗可用（Views/评论/表情/投票开关），CE **页面无发布入口**（行菜单 6 项均无发布）；CE space 首页只是「再一步」占位页，无站点目录。

## 页面结构对比（云端 Business vs CE）

### 云端页面发布流程（实测全过程）

1. 项目 → Pages → 打开「Project Design Spec」页面；
2. 编辑器头部按钮排：**发布** / 订阅 / 锁定页面 / Copy link / 收藏 / 评论 / 更多操作 / AI summary；
3. 点「发布」→ 弹窗「**发布页面**」：文案「生成公开 URL 以分享此页面。」+ 取消/发布（**无任何付费提示**）；
4. 确认后：弹窗变为已发布态——完整 URL `https://sites.plane.so/pages/f81e27445c914eb59993bf7d48217238`（复制/新开按钮）+「任何拥有链接的人都可以访问」+ 取消发布（红）/取消/**查看站点**；
5. 编辑器头部出现「已公开」绿点徽标 +「取消发布」按钮；
6. 公开站形态（sites.plane.so）：
   - URL 结构：`sites.plane.so/pages/<32位hex anchor>`（无 workspace/project slug，随机 anchor 寻址）；
   - 页头极简：左侧「📄 页面名」+ 右侧 复制链接 + 更多（…）；**无主题/品牌定制、无目录页、无登录墙**；
   - 正文：富文档只读渲染（H1-H3/表格/列表/引用/代码块），居中窄栏（~720px），白底黑字默认主题；
   - 底部无「Powered by」标识（对比 CE space 页脚有「Powered by Plane Publish」）。

## 待验证问题闭环

- **云端发布是否弹付费确认？** 已闭环：**页面发布不弹**——「发布页面」弹窗只有「生成公开 URL 以分享此页面。」，一键发布成功（截图 cloud-page-publish-modal / cloud-page-published-modal）。工作区视图则根本无发布入口，不存在弹窗。
- **CE 能发布什么？** 已闭环：项目 ✓（⋯→发布项目，弹窗含 Views/评论/表情/投票）；页面 ✗（行菜单无发布项，与代码盘点一致）；Intake ✓（55 模块 U6 实测走通）。space 首页为占位页而非站点目录（截图 ce-space-home）。
