### 1.4 Customers（云端）

- 列表页：侧边栏「客户」→ 表格（客户/阶段/合同状态等列）+ 搜索 + 创建客户记录按钮；空态/有数据态均实测。
- 创建弹窗（cloud-customer-create-modal）：客户名称\*/电子邮件/描述/网站/行业/员工/阶段（下拉）/合同状态（下拉）/收入；创建弹窗**无自定义字段**入口（自定义属性在工作区设置→客户→属性管理，本批未展开，见待验证 1）。
- 详情页（cloud-customer-detail-page）：面包屑 客户 > 调研-客户A；主区 tab「请求｜关联工作项」；右侧属性面板：电子邮件/网站/规模/行业/合同状态/阶段/收入 + 创建者/创建于/更新于。
- 请求（Requests）：客户详情→添加请求→（名称+描述）→请求详情内「关联工作项」选择器把工作项挂到请求（cloud-customer-request-\*）；工作项侧属性面板出现 **Customers 字段**（cloud-work-item-detail-customer-field、cloud-work-item-customer-picker），可反查客户。
- 阶段/合同状态为受控枚举（cloud-customer-stage-options、cloud-customer-contract-options）。

### 1.5 Releases（云端）

- 列表页：侧边栏「发布」→ tab「未发布/已发布」+ 搜索/筛选/创建时间排序 + 添加发布（cloud-releases-list-empty、cloud-releases-released-tab）。
- 创建弹窗（cloud-release-create-modal）：发布（名称，**全工作区唯一**）/描述/目标日期/负责人/标签（版本 tag，单个）/标签（label，多个）——底部一排 4 个属性按钮。
- 详情页（cloud-release-detail-page）：右上「立即发布 + ...」；tab「概览/范围/更新日志」；范围 tab 5 种布局（列表/看板/时间线/日历/表格）+ 筛选 + 添加工作项；更新日志为富文本自动保存（cloud-release-changelog、cloud-release-changelog-typed）。
- 状态流转：立即发布弹窗（cloud-release-now-modal）「发布"调研-Release 1.0"/1 个工作项将被发布/目标日期 选择发布日期/取消|发布」→ 发布后进入已发布 tab（cloud-release-after-publish）。**未实测「未完成工作项转移/忽略」分支**（本次范围工作项已完成，弹窗未出现该选项，见待验证 3）。
- 版本 tag/label 目录：创建弹窗内点击标签打开目录对话框（cloud-release-tag-dialog、cloud-release-version-tag-dialog）。

### 1.6 Milestones（云端，「预热中」形态实证）

- 顶层路由：`/thinkym/milestones/` 与 `/thinkym/projects/{id}/milestones/` 均 **404**（cloud-workspace-milestones-route、cloud-project-milestones-route）。
- 开关：项目设置→功能→里程碑，单卡片「启用里程碑：允许此项目按里程碑日期对工作进行分组」+ 文档链接，`data-testid=project-feature-toggle-is_milestone_enabled`，默认 false；翻开即 toast「Success! Project feature updated successfully.」（cloud-milestone-feature-page、cloud-milestone-toggle-on）。
- 开启后**侧边栏不新增任何项**（cloud-project-sidebar-after-milestone-on），但项目概览页顶部出现「Overview｜Milestones」子 tab（cloud-project-overview-after-milestone-on）。
- Milestones 页 `/overview/milestones/`：空态「添加里程碑/创建您的第一个里程碑/跟踪重要的项目里程碑及其目标日期」（cloud-overview-milestones-section）。
- 创建弹窗：标题\* + 目标日期（日历弹层）（cloud-milestone-create-form、cloud-milestone-date-picker）；创建后列表条目=名称+进度 0%+日期（cloud-milestone-created）。
- 详情：Link work items → 现有工作项多选弹窗（含全选）（cloud-milestone-link-picker）→ 关联后展示**时间线**（周/月/季度切换，gantt 条显示工作项起止，cloud-milestone-linked-workitem）。
- 其它痕迹：项目创建弹窗功能组含里程碑（56 号已录）；项目模板功能区含里程碑开关（本次 cloud-project-template-features-section）。

### 1.7 项目更新 Updates（云端）

- 开关：项目设置→功能→项目更新，卡片文案「发布状态更新，让任何人都能快速了解此项目进展。/启用项目更新：允许任何人在此项目上发布状态更新。」（cloud-project-updates-setting-off/on）。
- 入口：项目概览页**右侧面板第 2 个 tab**（时钟图标，与详情/活动并列），非侧边栏、非概览主区（cloud-project-overview-updates-area、cloud-project-overview-right-panel-tab2）。
- 空态：「No updates yet / You can see the updates here. / Add an Update」。
- 创建（cloud-project-update-create-form）：进度标记下拉（**进展顺利/有风险/偏离轨道** 三态，cloud-project-update-progress-options）+ textarea（placeholder 添加更新）+ 取消/添加更新。
- 发布后（cloud-project-update-posted）：卡片=作者「yueming0624 将状态更新为有风险」+ 相对时间 + 内容 + **进度快照「已完成 2/4，进度 50%」** + 评论入口；toast「Update created」。

### 1.8 模板 Templates（云端）

- 工作区设置→模板：空态文案「使用模板可以节省 80%创建项目、工作项和页面的时间。」（cloud-templates-workspace-empty）。
- 创建模板菜单三选项：**项目模板/工作项模板/页面模板**（cloud-template-create-type-menu）。
- 工作项模板表单（cloud-wi-template-form）：模板名称\*（placeholder「为您的工作项模板命名。」）/描述（「描述何时以及如何使用此模板。」）/Project（必选，下拉选项目）/工作项标题\*（「为此工作项提供标题。」）/类型（默认 Task）/状态（默认 无→选后显示 Backlog 等）/负责人/标签/**子工作项（可选）**。校验实测：空提交报「模板名称是必填项」「工作项标题是必填项」。
- 使用模板：列表条目「使用模板」按钮→**打开新建工作项弹窗并预填**（项目=绑定项目、类型=Task、标题=模板标题、状态=Backlog、右侧完整属性面板 + 子工作项区 + AI 标签建议），按钮态变「使用中」（cloud-wi-template-use-result）。
- 页面模板表单（cloud-page-template-form）：模板名称\*（「为您的页面模板命名。」）/描述/页面编辑器（标题 input placeholder「未命名页面」+ 正文 contenteditable「添加您的模板」）。校验实测：空提交报「模板名称是必填项」「此字段为必填项」（正文必填）。
- 项目模板表单（cloud-project-template-form）：模板名称\*（「为您的项目模板命名。」）/描述 + **内嵌项目配置**：项目名（「为您的项目命名。」）/项目描述/更改封面/网络（默认公开）/Lead/功能 7 开关（周期/模块/视图/页面/收集/时间跟踪/里程碑，各带说明文案）/状态（Backlog 默认/Todo/In Progress/Done/Cancelled）/标签（可建）/工作项类型（Task 默认+添加自定义属性、Epic）/工作项（可预置启动工作项）（cloud-project-template-features-section、cloud-project-template-all-sections）。
- 模板列表：工作项/页面/项目三分 tab，条目=名称+描述+使用模板按钮（cloud-template-list-page-tab、cloud-template-list-project-tab）。
- **新建项目弹窗无模板选择区**：添加项目弹窗仅 封面/项目名称/项目ID/描述/公开/Lead（cloud-create-project-modal-full），与官方文档「创建项目时 Pick a project template」不符（见待验证 2）。

## 5. 待验证问题

1. **客户自定义属性**：官方文档称可加自定义属性；工作区设置→客户分组的属性管理页本批未展开实测（创建弹窗无该入口）。
2. **项目模板的应用入口**：官方文档说创建项目时可选模板，但实测「添加项目」弹窗无模板区。可能需要模板存在后经其它入口（工作区首页引导/命令面板/项目设置内套用），或该能力仍灰度中。追赶时以「模板列表 Use template」兜底。
3. **Release now 的未完成项分支**：官方说发布时可选「转移未解决工作项/忽略」；本次范围工作项全部完成未触发该分支，弹窗仅目标日期。
4. 里程碑是否最终会有顶层路由/侧边栏入口（当前仅概览子页），以及 `is_milestone_enabled` 打开后周期列表/工作项属性是否新增 Milestone 字段——未逐一复查工作项属性面板。
5. 项目更新的可见性（Guest/评论者权限）、更新编辑/删除入口未实测；更新是否同步到工作项 Updates tab 亦未验证。
6. 客户/发布的 Guest 与 Member 权限边界单账号无法实测（官方：Guest 两者均不可见）。
