> CE：demo-workspace / WEB 项目（预置 Sprint 24 · Current、Sprint 25 · Next）

## 页面结构对比（云端 vs CE）

### 项目级 Cycles 页

| 区域         | 云端（GZRC，新建周期后）                                                                                                                                                                                                                                                                                   | CE（WEB）                                                                                                          |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 顶部         | 面包屑 + tabs：活动/即将发生/已完成 + 搜索 + 筛选 + "添加周期"按钮                                                                                                                                                                                                                                         | 分区折叠式：活动周期 / 即将到来的周期 / 已完成的周期 三段，右上 筛选 + 添加周期                                    |
| 活动周期卡片 | 展开式大卡片：0% 进度环 + 标题 + 日期 chip + 创建者头像 + 选项(...)；左侧 Breakdown 面板（🏃 Leading by N work items、Today's ideal Pending/Pending/Started/Scope、Other stategroups Done/Unstarted/Backlog、Excluded cancelled 计数）；右侧 **Burn-down for Work Items** 大图（今日标记线、Start/End 轴） | 三联卡片：进度条（Started/Unstarted 计数）+ 工作项燃尽图（Current vs Ideal）+ 右侧 优先工作项/受理人/标签 分布面板 |
| 周期详情页   | 路由 /cycles/{id}：主区按布局（列表/看板/日历/表格）展示周期内工作项 + 显示/Analytics/添加工作项；右侧栏：标题、日期+进行中 chip、属性（负责人/成员/工作项/创建者）、进度（状态/负责人/标签 tabs）                                                                                                         | 无独立详情路由（点击展开卡片内数据；从卡片可跳转到带周期筛选的工作项列表）                                         |
| 创建周期弹窗 | 标题/描述/日期范围（含"每个项目只有一个周期"的引导提示）                                                                                                                                                                                                                                                   | 类似（标题/描述/日期）                                                                                             |
| 空态         | "没有活动周期"说明文案                                                                                                                                                                                                                                                                                     | 无活动周期时段落收起                                                                                               |

### 工作区 Active Cycles 页

|      | 云端                                                         | CE                                                                                                                                                      |
| ---- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 入口 | 侧栏"更多"扩展面板 → 周期（/active-cycles/）                 | 侧栏无直接入口（扩展面板含 视图/分析/归档；active-cycles 路由存在）                                                                                     |

### Milestones（里程碑）

|          | 云端                                                                                          | CE                                                   |
| -------- | --------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| 设置入口 | 项目设置 → 功能 → 里程碑（"设置共享目标日期，并将工作项归在这些日期之下" + 启用开关，默认关） | 无（设置中无里程碑项）                               |
| 项目导航 | 开启后项目子菜单**无**里程碑入口；/milestones/ 路由 404（"Oops! Something went wrong"）       | 无                                                   |

## 差异点清单

| 编号        | 差异                           | 云端形态                                                   | CE 形态                              | 影响                                     | 难度                                          |
| ----------- | ------------------------------ | ---------------------------------------------------------- | ------------------------------------ | ---------------------------------------- | --------------------------------------------- |
| D-01-周期   | 工作区 Active Cycles           | 真实功能页（跨项目活动周期汇总）                           | 仅升级营销组件                       | U3 成立；CE 用户无全局周期视图           | M（CE 后端有聚合 API 与前端页面骨架，需放开） |
| D-02-周期   | 周期卡片形态                   | 展开大卡 + Burn-down 大图 + stategroup 分解 + Leading 指标 | 三联小卡（进度/燃尽/分布）           | 信息密度与视觉差距                       | M                                             |
| D-03-周期   | 周期详情页                     | 独立路由 + 侧栏属性/进度 + 可切换布局                      | 无独立详情页                         | 导航深度差异                             | M                                             |
| D-04-周期   | 并行周期/手动周期推进/自动排期 | 功能设置提供（并行、手动推进为付费 Upgrade 项）            | 设置无对应项（并行周期 CE 不可配置） | 高级排期能力                             | M                                             |
| D-05-里程碑 | 里程碑功能                     | 存在（设置开关，UI 页面未见落地）                          | 已移除                               | 暂无追赶需求，观察云端后续               | -                                             |
| D-06-周期   | 项目侧栏入口                   | 周期需在项目设置开启后才出现                               | 预置数据开启后直接显示               | 行为一致（CE 也按 feature flag），无差异 | -                                             |
