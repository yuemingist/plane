- 工作区设置侧边栏新增「集成」入口（云端在「连接」分组，50 号 D-01）；

## 8. 上游冲突面（风险：低-中）

- `integrations/page.tsx` 是官方已裁剪区域的恢复件——上游大概率不再触碰（17 号判定：silo 体系未回归开源、零提交）；但 propel 设计系统同步（#10038）会扫 `apps/web` 全域——新详情页放新文件，page.tsx 改动保持最小 diff。
- 死代码 service（github/jira.service.ts）**不删不改**（官方 merge 冲突避让；U9 记录其为死代码）。
- `workspace.ts` 设置常量与 P0-7 同文件——两批合并提交减少冲突次数。

## 9. 风险与未知项

1. **预期管理风险**：目录页出现"即将支持"卡片可能引发用户困惑——文案需明确（「即将支持，当前版本暂未开放连接」）；云端 Free 态卡片全"升级"态的同构观感问题在 CE 无套餐层，无需复刻。
2. 静态目录常量与官方卡片集漂移（官方增删集成）——低频，季度复核即可。
3. 方案 B（真实列表端点）若后期切换，page.tsx 数据源改造一次——推荐 A→B 的切换点封装在 service 层（现在就写 `integrationCatalog.service`，后续换实现不改组件）。
4. Draw.io 反向 OAuth（62 号 D-01）等高级形态在 CE 无 OAuth Provider 基础——明确不在本条（P2-9 生态域）。

## 10. 验收用例（对照 50 号 U8 / 62 号 1.1）

1. Given Admin，When 直连 `/demo-workspace/settings/integrations/`，Then 渲染集成目录页（10 张卡片），不再是 404 错误页。
2. Given 工作区设置侧边栏，Then 出现「集成」入口。
3. Given 点击 GitHub 卡片，Then 进入详情页（返回链接+卡片+描述），按钮为「即将支持」态。
4. Given Slack 卡片描述，Then 与云端实录一致（「将您的 Slack 工作区与 Plane 连接。」）。
5. Given Member 角色，When 访问目录页，Then 未授权视图。
6. Given 目录页，When 点击任何「即将支持」按钮，Then 不发起任何 OAuth/外呼（范围边界回归）。
