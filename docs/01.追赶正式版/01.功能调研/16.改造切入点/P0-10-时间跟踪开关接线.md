## 1. 目标与云端形态

把项目功能设置页补上「时间跟踪」开关项，使 `Project.is_time_tracking_enabled` 字段从"无 UI 消费"变为可管理（云端形态，56 号 3.1 步骤 4-5：项目设置 → 功能 → 时间跟踪 → 单开关卡片「启用时间跟踪：允许项目成员在工作项上记录工时。」；开关 DOM `data-testid="project-feature-toggle-is_time_tracking_enabled"` 与 CE 后端字段同名可直接复用）。**范围边界：本条只做开关接线**——Worklog 模型/记录工时弹窗/工时表/导出是 TM-02/TM-03（L，独立立项，18-07 号规格已备）；开关本身是 TM 域的地基与 P0 定位依据（13 号 539 行明确建议）。

3. `packages/types` 的 IProject 字段完整性需开发时核对（若官方类型文件已含此字段则零改动）。

## 10. 验收用例（对照 56 号 3.1 步骤 4-6）

1. Given 项目设置→功能，Then 出现「时间跟踪」开关项（现状：仅 周期/模块/视图/页面/接收 五项）。
2. When 翻开开关，Then toast 成功且 `is_time_tracking_enabled=true` 落库（刷新保持）。
3. When 关闭开关，Then 落库 false。
4. Given 非 Admin 成员，When 打开功能设置，Then 开关只读/隐藏（按 CE 现有功能开关权限模式）。
5. Given API 直调 `PATCH .../projects/{id}/ {"is_time_tracking_enabled": true}`，Then 200（字段已在 serializer fields，回归验证）。
6. Given 开关打开，When 打开工作项详情，Then 不出现工作日志 tab（明确边界：记录功能属 TM-02/03）。
