## 2. CE 现状（已实证）

1. **问候语**：`apps/web/components/home/user-greetings.tsx:47-52` —— `greeting = hour<12 ? "morning" : hour<18 ? "afternoon" : "evening"`，渲染 `{t("good")} {t(greeting)}`；`packages/i18n/src/locales/zh-CN/common.json:333-336` `"good": "早上"`（en 侧 good 应为 "Good"）——zh 误译致「早上 晚上」。
2. **intake 徽标**：`apps/web/components/inbox/sidebar/inbox-list-item.tsx:134` `createdByDetails.email?.includes("intake@plane.so")`——17 号考古：全历史唯一 "intake@plane.so" 即此处（2024-11 #5951 进入），非邮件通道实现。
3. **Intake 术语**：zh-CN locale 中 intake 相关键译名不统一（「收集」「接收」「收件」三处并存，31/23 号实测）；目标统一为「Intake」（产品名不译）。
4. **编辑器 i18n**：editor 菜单项 `name: "Text"` 等硬编码（menu-items.ts:72）；slash 菜单/浮动工具栏同源（30 号 D-14）。editor 包有 `editor.json` locale 命名空间（en 目录已存在）但未被菜单消费。
5. **设置搜索框**：`apps/web/components/settings/workspace/sidebar/` 无搜索组件；GROUPED_WORKSPACE_SETTINGS 结构（packages/constants/src/settings/workspace.ts:79-89）支持过滤实现。
6. **偏好三项**：`apps/web/components/settings/profile/content/pages/preferences/`（default-list.tsx 等）无 smooth cursor/comment submit key/weekend 项；rg `smoothCursor|weekend` 零命中（64 号 §6.4）。
7. **Overview**：`apps/web/app/(all)/[workspaceSlug]/(projects)/` 下无 overview 路由（64 号 §6.3，实测 404）。

2. 徽标判定：`inbox-list-item.tsx:134` 判定条件改为 `IntakeIssue.source`（或 created_by 为系统账号的可靠标识）——需与 P0-2 放开公开提交时的 source 值对齐。

## 8. 上游冲突面（风险：中-高——editor 包是唯一高危点）

- **`packages/editor` 文案文件是 17 号列名的高危同步区**（editor src/core 拆平 #9719/#9723 刚完成）——小项 4 的隔离策略：仅改 `menu-items.ts`/菜单组件的显示名引用（换 t() 调用），**不动 editor 数据结构/扩展注册**；若上游 merge 冲突大，此小项可降级延后，不阻塞其余。
- `common.json`/`inbox.json` locale：只改 zh 系键值与新增键，不重排 en 键（17 号 i18n 策略）。
- `user-greetings.tsx`、设置侧栏为低频区——低风险。

## 9. 风险与未知项

1. **Overview 立项评估结论**（64 号 D-03-Home，L）：完整形态依赖 Project states 启用卡（Pro 字段，64 号 D-04）与 Updates/活动三 tab——建议不进 P0，挂 P1-11 工作项单点包或独立 M 项；本包仅交付该评估记录。
2. 偏好三项中"评论提交快捷键"影响编辑器行为（Enter 提交 vs Cmd+Enter）——涉及 editor 提交逻辑一处判断，需谨慎（若冲突面大，首期只做"周末日"+“平滑光标”两项 UI 偏好，快捷键项延后）。
3. 术语统一会影响既有用户文案习惯（zh 译名变更）——一次性 changelog 说明。
4. 编辑器 i18n 全量覆盖（含全部 hint/占位文案）工作量可能超预期——本期限"菜单可见标签"，tooltip/深层文案二期。

## 10. 验收用例

1. Given zh-CN 且当前为晚上，When 打开首页，Then 显示「晚上好, {姓名}」（不出现「早上 晚上」连排）。
2. Given en，When 打开首页，Then "Good evening, …"（键重构后英文不回归）。
3. Given Intake 列表含公开表单提交项，When 渲染列表行，Then 徽标按 source 判定（非 email 硬编码）。
4. Given zh-CN 全站，When 打开页面编辑器，Then 工具栏/slash 菜单高频标签为中文（Text→文本等）。
5. Given 工作区设置侧栏，When 在搜索框输入 "web"，Then 仅剩 Webhooks 项。
6. Given 偏好设置页，When 设置周末日=Saturday,Sunday 并保存，Then 刷新后保持且后端字段落库。
7. Given 22 语言切换全走一遍，Then 无缺失键回退英文的明显残缺（高频面）。
