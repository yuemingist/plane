- **目标**：OIDC discovery 接入（workload 的自托管 SSO 首选项），身份页 OIDC 卡片+配置流。
- **CE 现状**：无通用 OIDC；现有实现模板=四家硬编码 OAuth（`apps/api/plane/authentication/provider/oauth/`），可仿其 provider 结构写 discovery 版。
- **改动面**：新 provider 模块 + discovery/jwks 解析 + 账号映射（email/sub）+ 身份设置页卡片（51 号 `cloud-identity-saml-oidc` 形态）+ 域名验证前置（简单版可先跳过）。
- **依赖**：无强依赖；与 P2-2 SAML 共享身份页骨架。
- **估算**：M（1-2 周）。
- **R7/考古引用**：18-10 号（GroupSync 可独立先行）；17 号第二部分（官方 preview 身份域零动作）。
- **上游冲突**：authentication provider 目录低频——新 provider 独立文件，风险低。
