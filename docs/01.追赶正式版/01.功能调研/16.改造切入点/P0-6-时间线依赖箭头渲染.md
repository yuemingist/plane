## 9. 风险与未知项

1. 云端连线的交互细节（点击连线行为？hover 高亮？）未实测（20 号仅静态截图）——按最小形态：静态渲染+hover 高亮，不做点击交互。
2. 甘特虚拟滚动/横向滚动下的连线重算性能——若明显掉帧，降级为"仅视口内两端可见时渲染"。
3. relations 批量取数端点的分页/过滤能力需开发时确认（issue.py:237 的 list 是否支持 project 级批量）；不支持则一次拉取当前甘特可见集。

## 10. 验收用例（对照 20 号 U11）

1. Given WEB-7 blocked_by WEB-4 且两块均有日期，When 打开工作项时间线布局，Then 两块之间渲染蓝色依赖箭头（方向=从 blocked 指向 blocker，对齐云端实拍）。
2. When 切换周/月/季度视图，Then 连线端点跟随条形位置重算，无错位。
3. When 横向滚动时间线，Then 连线跟随滚动（或视口策略生效且不闪烁）。
4. Given 无依赖关系的工作项，Then 时间线不渲染任何连线（与 CE 现状一致的干净基线）。
5. Given 删除 WEB-4 与 WEB-7 的依赖关系，When 返回甘特，Then 连线消失。
6. Given 周期/模块内甘特，When 存在跨块依赖，Then 同样渲染（若依赖对端不在当前甘特集，则不渲染——与云端行为对齐说明记录）。
