# 消费级细节 对比（实测日期 2026-11-14）

> 范围：个人资料/偏好设置（主题、语言）、快捷键面板、主题定制深度。
> 限制：云端"用户菜单"下拉无法通过浏览器自动化展开（合成点击无效），云端个人偏好/主题设置页未能实测；以 CE 实测为主，云端侧用工作区设置页与界面语言状态佐证。

## 页面结构对比（云端 vs CE）

### 个人偏好设置（CE `/settings/profile/preferences`）

- 侧边栏分组：Your profile（个人资料/偏好设置/通知/安全）、Developer（个人访问令牌）、工作区（各工作区入口）、创建工作区、工作区邀请。
- 内容分区：
  - **主题**：系统偏好（默认）/ 浅色 / 深色 / 浅色高对比度 / 深色高对比度 / **自定义主题**。
  - **语言和时间**：时区（UTC+08:00 Hong Kong）、语言、First day of the week（Monday）。

### 语言切换实测（CE，闭环通过）

- 语言下拉共 **22 种语言**：English、Français、Español、日本語、简体中文、繁體中文、Русский、Italian、Čeština、Slovenčina、Deutsch、Українська、Polski、한국어、Português Brasil、Indonesian、Română、Tiếng việt、Türkçe、ქართული、Nederlands、Български。
- 实测切换 简体中文 → English：整站即时生效（侧边栏/设置/标题全部变英文，toast "Success! Language updated successfully"）。
- 实测切换 → 日本語：同样即时生效（プロフィール/環境設定/通知/セキュリティ）。
- 实测切回 简体中文：生效。**结论：CE i18n 切换链路完整可用。**
- 已知覆盖缺口（实测发现）：页面编辑器工具栏/菜单为英文硬编码（Text/Color/Heading/Numbered list…），未走 i18n；Intake 页 "Filters"、工作区设置侧边栏部分项（Workspace settings/Developer/Administration）同为英文残留。

### 云端侧已确认的消费级细节（其它页面顺带记录）

- 全站中文（账号语言为中文，云端 i18n 生效且文案质量高，如"使用 AI 驱动的页面进行文档化"导览）。
- 工作区设置侧边栏含"搜索设置"过滤框。
- 首页widgets：问候语+日期、Ask Plane AI 卡（含模型选择 Claude Sonnet 5.5）、快速链接、最近访问、Stickies 便签、管理小部件按钮。
- CE 首页也有问候语/快速链接/最近/便签，但无 Ask Plane AI 卡、无"管理小部件"（有"管理小部件"按钮，实测存在）。
