# 66.2 组件覆盖矩阵（云端 Business 观察组件 ↔ CE 包内实现）

> 采集日期：2026-11-14
> CE 侧「包内证据」：`@makeplane/propel@0.9.7` dist/components 目录清单（code）与 `packages/blocks/src/*` 子路径导出（code）；「dom」= 本批或历史批次浏览器 DOM 观察

## D. 备注

1. 「需改造」项的共同模式：**底层组件一致，商业层形态不同**——追赶时优先调 token 档位选择（如卡片 rounded-lg→rounded-xl、列底色 bg-layer-1）而非重写组件。
2. 「需新增」14 项与模块级差异文档（20-65 各 `对比.md`）的功能差距一一对应，本表只记录**组件形态层**证据。
3. 云端 aria-label 体系与 CE 同名（「看板布局」「帮助」「打开用户菜单」等实测两侧一致），证明两侧共享组件命名约定——追赶时可继续沿用（dom）。
4. 云端一处未翻译 key（`aria_labels.app_sidebar.open_extended_sidebar`）在侧栏「更多」按钮上暴露（dom，2026-11-14）——追赶时注意 aria-label 也要过 i18n。
5. 组件计数依据：propel dist/components 60 个目录（code）；本批 DOM 普查 census 见 /tmp 采样 JSON（未入仓库），关键计数已写入各行观察证据。
