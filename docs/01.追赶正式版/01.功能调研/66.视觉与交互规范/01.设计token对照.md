> 采集日期：2026-11-14
> 云端来源：CDP + `getComputedStyle(document.documentElement)`（computed），浅色在工作区首页、深色在偏好设置切换后采集（均已恢复浅色）

## 6. 备注

- 「CE 有名可复用」含义：CE 的 propel `variables.css` 中已有该 CSS 变量名与值；开发 CE 新页面时可直接 `var(--x)` 引用，不必再造命名。
- 云端 root unset 的 3 个 token（backdrop 档位、raised-100/200、overlay-100、padding-page）反映云端 propel 版本更新；追赶时以**云端生效值**为准（升级 propel 或在 CE 侧覆盖）。
- 本表所有 computed 数值采集于 2026-11-14；CE code 数值对应 `@makeplane/propel@0.9.7`（`apps/web` 实际解析版本）。
