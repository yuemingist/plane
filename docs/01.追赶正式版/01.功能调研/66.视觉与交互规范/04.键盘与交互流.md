# 66.4 键盘与交互流（云端 ? 面板 vs CE ⌘/ 面板 + 交互行为对照）

> 采集日期：2026-11-14
> 面板来源：云端=帮助菜单（顶栏 ? 图标）→「键盘快捷键」弹窗，全文 DOM 抓取（`cloud-token-shortcuts-panel-2026-11-14.png`）；CE=帮助菜单→「键盘快捷键」（`ce-token-shortcuts-panel-2026-11-14.png`）。两弹窗均为 rounded-xl(12px) 白底面板（云端宽 638px / CE 547px，宽度差来自内容量）。
> 前批引用：64 模块已采云端偏好设置（含主题/语言）；32 模块已采命令面板（CE Power-K 序列键）；本批为**逐项全量对照**。
> 面板入口：云端面板自述「打开键盘快捷键 = /」（裸斜杠，聚焦非输入框时）；CE 面板自述「打开键盘快捷键 = ⌘/」。实测 CE 按 Ctrl+/ 弹出的是「自定义导航」弹窗（疑似冲突绑定/旧键残留，dom 观察）——CE 正确入口为 ⌊⌘/⌋ 或帮助菜单。

## 1. 快捷键逐项对照（同一分组内对齐排版）

键位写法：云端面板显示为裸键或 `X then Y` 序列；CE 面板显示为 ⌘/⇧ 组合或 `X 然后 Y`。「（CE 无此行）」= CE 面板没有该动作；「（云端无此行）」反之。

## 2. 键盘流差异总结

1. **两代键位哲学**：CE 的「工作项属性/生命周期」类操作全部带 ⇧ 前缀（⇧E/⇧C/⇧M/⇧S/⇧F/⇧L/⇧A/⇧R），复制类走 ⌘ 组合（⌘. / ⌘⇧' / ⌘⇧,）；云端已把这一整层迁到**裸键**（E/C/M/S/F/L/A/R/./'/,）。追赶裸键方案时必须解决云端面板自身的撞键缺陷（订阅 S vs 更改状态 S、收藏 F 在页面组重复出现），建议保留 CE 的 ⇧ 区分或按上下文作用域分流。
2. **序列键同构**：N-then（创建）、O-then（打开）、G-then（跳转）三组序列两侧同源；云端每组的增量全部对应商业实体（团队空间/计划/仪表板/客户记录/Applets）。CE 的 Power-K（`apps/web/components/power-k`）已实现同款序列引擎，追赶只需注册新动作。
3. **CE 独有**：⌘/ 键盘快捷键入口（云端为裸 /）、Ctrl+/ 自定义导航弹窗、⌘⌫ 删除。**云端独有**：打开 AI 助手（A）、批量删除入口、评论提交键可选（Enter 或 ⌘+Enter，dom）、平滑光标。
4. 面板 UI 本身同构（rounded-xl 白底弹窗、分组标题 + 动作行 + 右侧键帽 kbd），键帽样式 10px/4px 圆角（computed）；差异只在行数与键位。
