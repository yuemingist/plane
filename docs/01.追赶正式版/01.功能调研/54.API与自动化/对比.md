# API与自动化 对比（实测日期 2026-11-14）

> 云端：app.plane.so/thinkym（Business 试用）。Webhooks 页沿用昨日（2026-11-13/14）Business 态截图（见 50.集成生态）。
> CE：yuemingmac-mini.tail43aa97.ts.net:3000。
> ⚠️ 采集说明：本模块后半段浏览器截图表面持续超时（环境级故障），云端创建令牌弹窗/自动化页与 CE 自动化页/令牌页共 5 张截图缺失，字段清单以 DOM 快照文本为据（已逐字记录），结构可信度不受影响；已保存截图见文末清单。
> 结论速览：API token 两侧同为「personal token（创建时填标题/描述/过期）」形态；**云端有双入口**（工作区级 API 令牌页 + 账号级个人访问令牌），CE 只有账号级；自动化差距最大——云端=3 条内置规则（多「自动提醒」）+**自定义自动化规则引擎**（触发器/条件/操作）+**重复工作项**，CE=仅 自动归档/自动关闭 2 条。

## 页面结构对比（云端 Business vs CE）

### API 令牌（token 管理入口矩阵）

| 维度                     | 云端 Business                                                                                                                                                                      | CE                                                                                                      |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 工作区级入口             | **有**：工作区设置 → 开发者 → **API 令牌**（/settings/access-tokens，与 Webhooks 并列）；页面=「创建令牌，用于验证来自外部系统的 API 请求。」+ 添加访问令牌 + 空态「暂无访问令牌」 | **无**：工作区设置 Developer 分组只有 Webhooks（51 模块已证）                                           |
| 账号级入口               | **有**：头像菜单 → 设置 → 个人资料设置弹窗 → 开发者 → **个人访问令牌**                                                                                                             | **有**（同一组件）：个人资料设置弹窗 → Developer → 个人访问令牌；空态「暂无个人令牌」+「添加 API 令牌」 |
| 创建令牌弹窗（云端实测） | 「创建令牌」：标题\* / 描述 / 过期时间（日期选择）+ **永不过期**开关 / 取消·生成令牌                                                                                               | 同形态（本次未展开 CE 创建表单，代码同源 `apps/web` 组件）                                              |
| 鉴权方式                 | 令牌即 API key（`Authorization: Bearer <token>`，云 API v1）                                                                                                                       | 同为 personal token（`X-API-Key`）                                                                      |
| 结论                     | **形态一致：均为个人级 token，无「服务端 API key/OAuth app」分级**；云端多一个工作区级管理入口（便于管理员统一管理）                                                               | CE 缺工作区级 token 管理入口                                                                            |

## 待验证问题闭环

- **云端自动化入口在哪？** 已闭环：项目设置 → 自动化 分组（自动化+重复工作项）；工作区级的「工作空间治理」也可集中管工作流/自动化/模板（51 模块，Enterprise 锁定）。
- **创建自动化构建器字段？** 未闭环：连续 3 种方式点击「创建自动化」均未弹出（role/坐标/dom_cua），疑为页面加载或环境故障；已如实记录，留待后续补测（规则引擎存在性本身已由空态文案+按钮证实）。
- **token 形态对比（personal vs 服务端 key）？** 已闭环：两侧均只有 personal token（无服务端 API key/OAuth client 概念）；云端的「API 令牌」页虽在工作区设置下，创建的仍是同形态令牌。
