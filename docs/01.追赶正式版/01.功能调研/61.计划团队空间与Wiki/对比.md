### 1.2 云端侧栏形态对比（核心信息架构差异）

- 云端顶层：**Work / Wiki / AI / 设置** 四组；Work 内含 首页/草稿/我的工作/Stickies + 工作区（项目/计划/团队空间/更多）+ 项目列表。更多浮层=视图/周期/分析/归档/计划/客户/仪表板/发布（均可固定钉选）。
- CE 顶层：仅 **Projects** 一组；更多浮层（项目级）= 视图/周期/分析/归档/仪表板（无 计划/客户/发布；cloud-sidebar-more-expanded vs 56 号 CE 截图）。
- 启用团队空间后 CE 侧没有对应能力：云端会在工作区组下**追加「团队空间」分组**，把成员空间与项目并列。

### 1.3 Initiatives（云端实测）

- 设置页（cloud-initiatives-settings）：卡片「启用计划：将项目归入共享目标，并跟踪其整体进度」+ 标签区（启用前锁定提示「启用计划功能后，即可整理和跟踪计划标签」，启用后出现 添加标签/空态）。启用 toast「成功！计划功能已成功启用。」
- 列表页 `/initiatives/`：布局切换（列表/看板/时间线三图标）+ 筛选 + Display + 添加计划；空态「从一个地方跟踪项目和史诗/使用计划对相关项目和史诗进行分组和监控。查看进度、优先级和成果— 全部来自单个屏幕/创建计划」。启用后侧边栏工作区组出现「计划」，更多浮层出现「计划」（cloud-sidebar-more-expanded）。
- 创建弹窗：计划名称\*（placeholder「计划名称」）+ State（默认 **Drafts**）+ 日期范围 + 负责人 + 选择标签 + 取消/创建计划。
- 列表条目：名称/State（Drafts）/工作项数/Lead。
- 详情页 `/initiatives/{id}/`：顶部 emoji+名称（标题旁 **字符计数器 X/255**）+ 概览 + 进度环 % + 「1 At risk」状态更新指示（来自关联项目的最新更新，实测来源=项目更新「有风险」）+ 添加项目/添加工作项 + **进度分布条**（Backlog/Unstarted/Started/Completed/Cancelled 各组计数与百分比，随关联项目实时汇总）+ 范围分解（项目 x 50%）+ 右侧属性面板（State/项目 0 projects→1 project/工作项/负责人/Start date/Due date/Labels/创建者）。
- Scope 页 `/initiatives/{id}/scope/`：tab **工作项/项目** + Display 布局 + 添加工作项 + 空态「在此空间中链接工作项并跟踪该工作」。
- 关联项目弹窗：搜索+项目列表（SURVEY/thinkym）+「已选择 0 个选项」+取消/确认；确认后 toast「计划项目更新成功」，进度 0%→50%、At risk 指示出现。

### 1.4 Teamspaces（云端实测）

- 设置页（cloud-teamspaces-settings）：「启用团队空间：团队空间成员可以访问其团队空间关联的所有项目。」开启后显示「已开启团队空间」。
- 列表页 `/teamspaces/`：Add Teamspace + 空态「使用团队空间解锁更好的组织和跟踪/为每个真实世界的团队创建专用空间…」。
- 创建弹窗：名称\*（placeholder「Name this teamspace.」）+ emoji + 团队负责人（选择团队负责人）+ 团队成员（从成员列表选择）+ Cancel/Create teamspace。
- 详情 Overview：Get started 空态「You haven't linked any projects…Link a project」+ 属性（Lead 选择团队负责人）+ Linked entities（Projects/Work items/Cycles 计数行，均带跳转箭头）+ Entities in the teamspace（Views/Pages 计数行）。
- **关联项目弹窗异常（重要发现）**：「将项目关联到调研-TeamSpace」搜索+列表区域显示「没有匹配的项目/未检测到符合匹配条件的项目。创建一个新项目。」——工作区明明有 2 个项目，输入「调研」过滤后仍为空（cloud-teamspace-link-project-search）。疑似缺陷或隐藏门控（见待验证 2）。
- 子页：/projects/（Projects 空）、/pages/（**Add page/Public/Archived/Date modified/筛选**——团队级页面）、/views/（Add view + 空态「您团队的工作视图，不会干扰工作空间中的其他视图…创建视图」）。周期 tab 由 Linked entities 行跳转（未展开实测）。
- 启用后侧边栏出现「团队空间」分组并列出成员空间（cloud-teamspace-link-project 截图侧栏可见）。

### 1.5 Wiki（云端实测）

- 全局结构：侧栏顶层「Wiki」组 → 主区含 **New page** 按钮 + 主页（问候+最近页面+Sticky 小部件）+ **集合（Collections）** 区（默认 General，带展开/折叠与悬停「创建集合」按钮）+ **Shared**（No shared pages）+ **Private**（私有页列表）+ **Archives**（cloud-wiki-home、cloud-wiki-sidebar-after-private）。
- 集合页 `/wiki/collections/general/`：标题+可见性徽标（公开）+「添加页面」+ 描述「你工作区的通用集合。此集合对该工作区中的所有人可见」+ 表格（**页面名称/所有者/嵌套页面/标签/最后活动/操作**）。General 内有预置页「Welcome to Company's Wiki」（所有者显示 `-`，疑似官方种子页）。
- `/wiki/collections/` 索引路由 **404**（集合无独立索引页，只在侧栏与各集合路由）。
- 创建集合弹窗（悬停集合区头→aria-label「创建集合」）：标题\*（「为集合输入一个标题」）+ **可见性单选：公开（工作区中的所有人都可以访问此集合）/ 私有（只有您添加的人员可以访问此集合及其中的页面）** + 取消/创建集合。
- 页面编辑器 `/wiki/pages/{id}/`：面包屑 集合>页面名；头部 发布/订阅（访问后变取消订阅）/文本/颜色（两下拉）/**AI summary**（生成/重新生成/删除摘要，Powered by Plane AI）/Icon；工具栏 文本/颜色/B/I/U/S/对齐/编号/项目符号/待办/引用/代码/表格/图片/附件；空页含 **「从模板中选择」**（有内容后消失——实测应用模板后按钮消失）。
- 模板应用：点「从模板中选择」→ 选择器列出 调研-页面模板A → 应用 → 标题与正文被填充（cloud-wiki-page-template-picker/-applied）——**模块 60 页面模板的应用路径验证完成**。
- 页面「更多操作」菜单：全宽（开关）/固定工具栏（开关）/复制 Markdown/版本历史/分析/创建副本/**移动页面**/设为私有/导出/Archive（cloud-wiki-page-more-menu 实拍）。
- 头部其它：锁定页面（aria「锁定页面」）/Copy link/Add to favorites/打开评论/订阅。
- 页面标签：工作区设置→Wiki→**页面标签**（`/settings/wiki/page-labels/`）：标签管理页（空态「暂无标签/创建第一个标签即可开始」+ 添加标签→名称+颜色→「标签已成功创建」）。集合表格行内「选择标签」多选应用，应用后行内显示标签（cloud-wiki-page-labeled）。
- 隐私边界：页面级「设为私有」菜单项存在；集合级创建时选 公开/私有；侧栏 Shared/Private 两个区按可见性分组（Private 区已有前批 AI 会话留下的「Private Wiki Page」）。实测对集合内页面点「设为私有」后页面仍留在 General 集合表格中（行为待复核，见待验证 4）。
- 嵌套：集合表格有「嵌套页面」计数列，但侧栏页面行悬停无「+ 子页」按钮（侧栏仅有 展开集合/折叠集合/添加页面/集合选项），本批未找到显式建子页入口（疑拖拽或移动页面对话框，见待验证 5）。

### 1.6 Governance（云端，只读）

工作区设置→工作空间治理：说明文案「集中并标准化工作区中项目的配置方式…项目可以导入和使用这些配置，但不能独立创建或修改它们」+ 文档链接 + 「启用治理：在工作区级别集中项目配置。**此操作是永久性的且无法撤消**」+ **升级** 按钮（Enterprise 门控，本批未点击）。
