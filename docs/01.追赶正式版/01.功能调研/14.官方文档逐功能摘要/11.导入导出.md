# 11. 导入器（Importers）与导出（Export）

> 抓取日期：2026-11-14｜来源：docs.plane.so/importers/\*（11 页）、/core-concepts/export｜对应 F-ID：待 R1 映射

## 定义

导入器把外部工具数据迁入 Plane；入口 Workspace settings→Imports；**仅工作区 Admin 可操作**；Cloud 与商业自托管可用（部分例外注明）。

## Jira（Cloud / Server / Data Center）

- 连接：PAT+邮箱+域名；Server/DC 同引擎。
- 步骤：选目标项目→选 Jira 站点与项目（可加 JQL，自动限定项目内）→导入用户（仅 Cloud：CSV 上传推荐或跳过；跳过则评论作者显示为迁移执行人、指派人为空）→状态映射（可自动建剩余）→优先级映射→确认。
- 导入内容映射表：issue→工作项；描述格式保留+内嵌图重传；状态/优先级映射；issue types→工作项类型（需项目开启 Work item types，自动创建不映射；Free 或未开启则不带类型）；Epic 作为普通类型导入；标签全部加 `JIRA IMPORTED`；自定义字段→自定义属性（不支持的跳过）；Reporter→创建人+reporter 属性；评论含作者时间；附件；子任务/父子；链接（blocks/blocked by/relates/duplicate；无对应的建自定义关系类型；跨项目链接待双方导入后解析）；Sprints→Cycles（含项与日期）；Components→Modules；Fix versions→自定义属性；story points；worklogs（自动开启时间跟踪）；watchers→订阅者；变更历史→活动；起止/创建日期。
- 每个导入项带 Linked Jira Issue 链接并保留原 Jira key 号。
- 重跑：同配置全量重同步，按原 Jira 身份去重更新不产生重复；Server/DC 失败可 Resume（约 7 天窗口）。
- Server/DC SSO 拦附件下载的需自建附件下载端点（ScriptRunner）绕过。

## CSV（自托管也可用）

- UTF-8；一行一项；表头大小写不敏感、空格=下划线；多值用 `|`；自定义属性列名须与属性名一致。
- 前置要求：状态/类型/周期/估算点/成员/自定义属性必须已存在（匹配失败静默回退默认或留空、无警告）；**标签是例外：不存在则自动创建**。
- 列：Name（必填，唯一必需列，空行报错跳过）/Description/Priority（必须小写五值之一，否则该行失败）/起止日期（YYYY-MM-DD；截止不得早于开始）/State Name（精确含大小写匹配）/Issue Type（精确；Epic 不能以此导入，回退默认类型；该列决定适用哪些自定义属性列）/Labels/Assignees/Subscribers/Comments（时间;作者;内容）/Links（URL;标题）/Cycle Name/Estimate/Identifier/Parent。
- 进度在 Migrations 表显示 Transforming→Finished。

## Flatfile（仅 Cloud，Beta）

- 交互式字段映射+行内编辑的 CSV 导入；自托管用 CSV importer。

## Linear / Asana / ClickUp

- 均为 PAT 连接+Migration Assistant；Linear 导入 issues/states/labels/priorities/users；ClickUp 需 List 在 Folder 内，含 projects/tasks/members/custom fields/attachments/comments；导入类型需先开启 Work item types。

## Notion / Confluence（Business，页面导入）

- Notion：仅支持 HTML 导出 ZIP（Everything+子页+建文件夹）；落到 Wiki/项目/团队空间。
- Confluence：XML 优先（HTML legacy 也支持）；保留页面层级。

## GitHub Importer（旧）

- 仓库 issue→Plane 工作项基础字段映射；文档标注 noindex（疑似弃用边缘态）。

## Export（/core-concepts/export）

- 工作区 Admin：Workspace settings→Exports→选全部或单项目→CSV/Excel/JSON→可加过滤器→ZIP 打包后台生成；Previous exports 记录状态/时间/人/格式；**文件 7 天后过期**；可 Refresh status。
- **Custom exports（Pro）**：从工作项列表/周期/模块/视图菜单直接 Export，按当前过滤器导出（同 03/04 域所述）。
