# 17. 工作区（Workspace）、项目（Project）与个人账户

> 抓取日期：2026-11-14｜来源：docs.plane.so/workspaces/_、/core-concepts/workspaces/_、/core-concepts/projects/_、/projects/_、/core-concepts/account/\*、/core-concepts/stickies、/your-work、/core-concepts/power-k、/workspaces-and-users/search-workspace、/customize-navigation｜对应 F-ID：待 R1 映射

## 工作区

- 四级结构：Workspace→Teamspace/Project→Work item；工作区是访问、报表与计费的边界；**官方建议多数组织只用一个工作区**（跨工作区不共享任何数据）。
- 创建：名称 ≤80 字符；URL slug ≤48 字符（字母数字连字符）**创建后不可改**；保留 URL 不可用；无数量上限（自托管可由实例管理员关闭创建）。
- 新工作区自带：owner 身份、示例项目、Wiki（General 集合）、默认项目状态、默认关系类型。
- General 设置：logo/名称/公司规模/时区可改；URL 只读；Owner/Admin 编辑，Member/Guest 只读。
- 离开：不能是唯一 Admin/Owner，也不能是某项目唯一 Admin；离开后内容保留、成员关系停用（受邀回归即恢复）。
- 删除：仅 Owner；需先取消付费订阅/试用；确认输入工作区名+`delete my workspace`；永久不可恢复。
- 所有权转让：可提升他人为 Owner；**Owner 无法自行降级/转让**，需联系支持（Cloud）或实例管理员命令（自托管）。
- 成员管理：两标签 People / Agents and apps；Guest 不能打开该页；列表列（姓名/显示名/邮箱（Guest 不可见）/角色/认证方式/加入日/计费状态）；被移除成员保留为 Suspended；搜索/角色过滤/排序/每页 10-100；**移除成员后席位回池不减账**；邀请受阻三情形（席位不足/角色高于自己/域名被禁）；CSV 批量导入成员（Pro）：email 必填，角色数字 5=Guest/15=Member/20=Admin，直接加入不发邀请邮件。

## Workspace Governance（EG）

- 把状态/工作流/工作项类型/模板/自动化/周期项收归工作区集中管理；**开启永久不可逆**。
- 启用走迁移向导（六步预览），迁移期间工作区配置**写冻结**。
- 项目 Admin 只能"使用"不能"创建编辑"；新项目自动用共享配置。
- 工作流 governance mode：Any/Constrained（allowlist）/Required（强制）；可 Pin 单项目；effective workflow 解析：Required→Pin→项目自选→工作区 default；换工作流时失配状态的工作项移到 fallback（有预览）。

## 导航与个人化

- Customize navigation：侧栏显隐+拖排序（个人）；项目导航两种风格 Accordion（侧栏手风琴）/Horizontal（项目内顶部标签页）；可限制侧栏项目数（最近访问优先）。
- Search workspace：`Cmd/Ctrl+K`；分类型标签（All/Projects/Work items/Cycles/Modules/Views/Pages/Teamspaces/Comments，含计数）；实时+部分匹配+大小写不敏感；只搜权限内内容（私有项目/归档/删除项不出现）。
- Power K：命令面板；搜工作项/周期/模块（可扩展全工作区）；快速设置/快捷键/文档/支持；创建任意实体；工作项页内改状态/优先级/指派/复制链接。
- Your Work：Summary（assigned/created/subscribed 计数）+Workload 五状态分布+按优先级/状态图表+最近活动。

## 项目（Project）

- 创建：`N,P`；名称 ≤255 工作区内唯一（含归档）；**Project ID ≤10 字符字母数字、唯一（含归档）、可后续修改**；Network Public（默认）/Private；Lead 自动成为项目 Admin；封面/emoji。
- 公开项目：全部成员可见可自加入（Guest 除外）；私有项目：仅邀请+工作区 Admin 直通。
- 归档/恢复/删除：归档保留一切只读；删除永久。
- Project states（Pro）：与工作项状态无关的另一套；工作区级六组 Draft(默认)/Planning/Execution/Monitoring/Completed/Cancelled；每项目另有优先级（五档）/lead/成员/起止日期/标签（Business）；空状态才可删、默认不可删、名称工作区唯一；列表可按状态/优先级/lead 分组。
- Project labels（Business）：工作区级、贴在项目上；≤255、唯一；随 project states 开启显示；分组 No Label。
- Project Overview（Pro）：描述（富文本+反应+链接附件）/进度五组条/属性侧栏（State/Priority/成员/lead/标签/倡议/起止）/Milestones 标签/Updates 标签/Activity。
- Project settings：General（名称/标识符/描述/网络/封面/logo/**项目时区**——周期与周期项按项目时区 00:05 执行，成员按个人时区显示）/Members（lead/default assignee/项目订阅者/链接的团队空间）/Worklogs/Imports（CSV）/Audit logs（EG）/Features 十个开关（cycles、modules、views✓默认、pages✓默认、intake、time tracking、milestones、releases、project updates、memory）/Work structure（states/labels/estimates/epics→类型/templates）/Execution（workflows/automations/recurring work items）；治理开启后 States/Labels/Workflows 移交工作区；归档项目不可改设置。

## 个人账户

- Home：问候+三 widget（Quicklinks/Recents/Your stickies）可开关与拖排序；Quicklink=URL+可选标题，删除无确认。
- Account settings：Profile（头像/封面/姓名/显示名/邮箱；注销账号=退出全部工作区但内容保留）；Preferences（主题 System/Light/Dark/High contrast/Custom 五色定义；每周首日；Smooth cursor；时区与语言）；Notifications（见 07 域）；Security；Activity。

## Stickies

- 私有便签，工作区各一套；自动保存；同空便签冲突提示；Bold/Italic/To-do/背景色；Home/Wiki home 均有入口；Free 自托管下 app rail 图标隐藏；删除不可恢复；可拖排序。
