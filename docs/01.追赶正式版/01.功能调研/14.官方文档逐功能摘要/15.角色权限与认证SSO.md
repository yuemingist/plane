# 15. 角色与权限、认证（SSO/组同步）

> 抓取日期：2026-11-14｜来源：docs.plane.so/roles-and-permissions/_（5 页）、/authentication/_（2 页）｜对应 F-ID：待 R1 映射

## 角色体系（roles-and-permissions/overview.md）

- 双模型：RBAC（系统角色，全计划）+ GAC（自定义角色=权限 scheme 组合，仅 Enterprise Grid）。
- **改名**：工作区 Admin→Workspace Owner；项目 Member→Contributor；Guest 的"view access"开关→Commenter 角色（自动迁移）。
- 作用域层级：Workspace⊃Project⊃资源；Teamspaces 通过"链接"向项目授予；权限向上继承。
- 条件授权两种：**creator**（仅自己创建的资源，如 Contributor 删除自建工作项）与 **lead**（团队空间负责人）；无条件授权恒优先于有条件授权。
- 判定顺序：本作用域角色（无条件→有条件）→团队空间 link 关系→父作用域递归→默认拒绝。
- 工作区 Owner/Admin 对全部项目资源有通配权（无需项目成员身份）。
- 公开项目自动加入的角色映射：Owner/Admin→项目 Admin；Member/自定义→Contributor；Guest→Guest。
- **Guest 天花板**：工作区 Guest 加入项目只能被授予 Guest 或 Commenter，不能 Admin/Contributor/自定义角色（防提权）。
- 缓存：用户权限 5 分钟、角色定义 24 小时；变更即时失效。
- 计划可用性：Owner/Member/Guest 与项目四角色全计划；Workspace Admin 角色、自定义角色、自定义 scheme：Business+/Enterprise Grid（表格标注 Admin 角色=Business+；自定义角色=EG）。

## Member roles（系统角色清单）

- 工作区：**Owner**（唯一可删工作区/转让所有权）/**Admin**（Business+；全域管理不可删工作区；无需项目成员即可进任意项目）/**Member**（标准内部成员；未入项目无项目内容；公开项目加入即 Contributor；"让成员建项目"开关默认仅 Owner/Admin 建项目）/**Guest**（只看被显式加入的项目；入项目只能 Guest/Commenter）。
- 项目：**Admin**（全控含归档删除项目）/**Contributor**（增改工作项/模块/周期/页面/视图；删自建内容；不能动设置/成员/标签/状态）/**Commenter**（看全部+评论反应+提交 intake）/**Guest**（仅 intake：提交表单+看改删自己提交的 intake 项；看不到工作项）。
- 团队空间：单角色；lead 条件授权（编辑设置/删空间/管成员/删他人内容）；Owner/Admin 越过成员身份全可。
- 层级约束：只能管理角色级别低于自己的人；仅 Owner 能管 Owner；最后一个 Admin/Owner 不能退出或降级；项目最后一个 Admin 不能退出。
- 付费席位：Owner/Admin/Member/自定义=计费；**Guest 不计费**。

## Custom roles（EG）

- 工作区/项目两级自定义角色；创建后零权限，靠附加 scheme。
- 约束：不能含 Delete Workspace/Transfer Ownership/完全访问；工作区作用域不跨工作区；占用付费席位。
- 基于"系统角色+"模式：挂系统 scheme 再叠自定义 scheme；引用同一 scheme，系统 scheme 更新自动同步。
- 删除角色时需为成员选替代角色。

## Permission schemes（EG）

- 命名权限包；系统 scheme（Workspace Owner/Admin/Member/Guest、Project Contributor 等）带 System 标记不可改删。
- 组合规则：并集；无条件胜有条件；**只能加不能减**；依赖自动管理（开 Edit 自动开 View；关依赖自动关下游）。
- 编辑 scheme 立即影响所有挂载角色。

## 认证（authentication）

### sso.md（Business；Plane Cloud 的 Identity 页）

- 前置：域名验证（TXT 记录；一个域名同一时间只能在一个工作区验证）。
- OIDC：取 Origin/Redirect/Logout URL→IdP 建 Web 应用→回填 client id/secret/scopes；适配 Google Workspace/Auth0/Okta/Keycloak。
- SAML：同样先取元数据再回填；两协议并存可配。
- （同域文档组还有 group-sync 见下。）

### group-sync.md（IdP 组同步；EG；自托管商业/Airgapped 版）

- 把 IdP 组映射到：工作区角色 / 项目成员与角色（或全部项目）/ 私有 Wiki 集合访问（view/comment/edit）。
- 提供商：OIDC/SAML/LDAP（一次一个）；**SAML 仅登录时同步**（组只在断言里）；OIDC/LDAP 支持登录同步+每 2 小时离线同步。
- 设置：Sync on login（默认开）/Offline sync（默认关）/Auto remove（默认关：无匹配组时移出工作区与项目）/Group attribute key（默认 `groups`，可 roles/memberOf/custom:groups）/Default workspace role（自动加入且无映射时）。
- 多组命中取**最高**角色/访问。
