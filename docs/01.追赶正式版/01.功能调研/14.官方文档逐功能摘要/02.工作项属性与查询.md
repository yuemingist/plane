# 02. 工作项属性、状态、布局与查询

> 抓取日期：2026-11-14｜来源：docs.plane.so/core-concepts/issues/\*｜对应 F-ID：待 R1 映射

## 覆盖页面（11 页摘要）

### states.md（状态）

- 状态归项目所有（项目 Admin 在 设置→States 管理）；Enterprise Grid 开启治理后为工作区共享目录（工作区 Admin 管理，项目只读）。
- 五个状态组：Backlog / Unstarted / Started / Completed / Cancelled；默认状态名 Backlog、Todo、In Progress、Done、Cancelled。
- 组决定行为：仅 Completed 组计为"完成"（进度/燃尽/分析）；仅 Completed/Cancelled 可自动归档；排序=组序+组内位置。**改组会改变所有统计归类**。
- 默认状态恰好一个，新项目默认 Backlog；治理下"默认"=工作流起始状态（默认 Todo），无 Mark as default。
- Triage：系统保留状态，每项目（治理下每工作区）一个；"Triage"为保留名不可用；不可建 Triage 组状态、不可删；不进普通状态列表与分析。
- 删除规则：默认状态不可删；有工作项的状态不可删（无自动迁移）；组内最后一个不可删；治理下被工作流引用的不可删。重名拒绝（治理下工作区级唯一、大小写不敏感）。
- 工作流里每状态有"允许直接新建工作项"开关。

### labels.md（标签）

- 标签归项目；管理集合需项目 Admin，应用标签=编辑工作项即可。
- 名称必填 ≤255、项目内唯一（大小写不敏感）；仅名字+颜色（description 存在但应用不显示，仅 CSV/API 可设）。
- 分组：拖拽 A 到 B 上形成父子；仅一层嵌套；删除父级级联删子级。
- 无数量上限；删除后名字可复用。
- CSV 导入（Pro）：列 name/description/color；只创建新标签、跳过重名、不建分组、后台跑、可下载错误报告。
- Plane AI 可按标题/描述预测标签。

### estimates.md（估算）

- 默认无估算系统；项目 Admin 在 设置→Estimates 添加。
- 三类：Points（Linear/Fibonacci/Squares/自定义）、Category（T 恤/难度/自定义）、Time（Pro，预设 1h/2h/3h/4h/5h30m/6h30m 或自定义）。
- **每项目同时只允许一个活跃估算系统**（旧版多系统已废弃归档）；Free 计划自定义估算值上限 6 个，Pro 以上不限。
- 可编辑值、可切换系统类型。

### layouts.md（布局）

- 五布局：List（分组/层级/拖拽排序）、Board（看板列+子分组+拖卡改状态）、Calendar（按截止日期，无日期不显示，拖动改日期）、Table（表格键盘导航+批量编辑）、Timeline（甘特条/拖拽改期/关键路径/依赖）。

### display-options.md（显示选项）

- 可显示属性 18 项（ID/类型/负责人/起止日期/标签/优先级/状态/子项数/附件数/链接/估算/模块/周期/依赖/客户数/客户请求数/发布等；Table 另有里程碑/创建于/创建人/更新于）。
- Group by 13 项（含 Milestones——仅 List/Board 且不可子分组；Parent type——按父项类型分组且与"显示子项"互斥）；Sub-group 10 项；Order by 6 项（Manual/Last Created/Last Updated/Start Date/Due Date/Priority）；显示子工作项、显示空组开关。

### bulk-ops.md（批量操作，Pro）

- 仅 List/Table 布局；先选中后底部改属性，点 Update 才生效。
- 常规可改：状态/优先级/负责人/起止日期/标签；部分计划另可改周期/估算/模块/发布（文档 TODO 定档）。
- 不能批量改类型；遵循单项的所有规则（如工作流状态迁移限制）并报错说明。
- 批量复制 ≤1000 项、后台执行；目标项目无 Epic 类型时 Epic 降级为普通项；批量订阅（铃铛）；批量归档（非完成态会报错）；批量删除。

### timeline-dependency.md（时间线依赖，Pro）

- 无开关，随计划自带；三种依赖：Finish-to-start / Start-to-start / Finish-to-finish。
- 连接线在两端日期齐备时绘制；红色=日期违反依赖；分页加载未加载的项无连线。
- 拖拽条/边改日期自动顺推（push）链上工作项：只会推迟不会回拉；改动按日历天、条最短 1 天；保存失败回滚；详情面板改日期不触发顺推；已冲突的保持重叠。
- 连接时不能连自身、不能与已有依赖/关系的项重复连接；点击连接线可查看/删除（无确认）。

### work-item-url.md（URL 建工作项）

- `https://app.plane.so/work-items/new?title=...&priority=...&assignee=me,...` 支持参数：workspace/title/description/project(标识符或UUID)/priority(urgent|high|medium|low|none，大小写不敏感)/assignee(UUID或显示名或me，逗号分隔)/start_date/due_date。
- 需登录；非法参数静默忽略；预填可再改。

### visualise_filter.md（过滤器）

- 过滤器独立一行；字段×算子矩阵：Title(含 contains)、Milestone、Type、State、State Group、Assignees(支持 is empty)、Priority、Mentions、Label(is empty)、Cycle(is empty)、Module(is empty)、四个日期字段（13 种日期算子含 between/not between/is empty）、Created by、自定义属性（按类型给算子：文本/数字 13 种/下拉/布尔/日期/成员/URL）。
- **算子按计划分级：Free 仅有 is（日期另有 between）；付费解锁 is not / is not any of / after / before 等**（contains、is empty 等标注"即将增加"）。
- 里程碑规则：一项同时只属一个里程碑且须同项目。

### plane-query-language.md（PQL，Pro）

- 文本查询语言：`Field Operator Value` + AND/OR/NOT + 括号 + `ORDER BY`(ASC/DESC) + `LIMIT`(≤1000)。
- 字段：id(支持序号比较)/title/text(标题+描述)/type/state/stateGroup/priority/assignee/label/cycle/module/release/milestone/mention/createdBy/project/startDate/dueDate/createdAt/updatedAt + 自定义属性。
- 算子：= != ~ IN NOT IN < <= > >= BETWEEN IS NULL IS NOT NULL。
- 值函数：日期（today/startOfWeek/daysAgo(n)…）、用户（currentUser/inactiveUsers/workspaceMembers/membersOf/userPropertyEquals）、周期（activeCycle/completedCycles/upcomingCycles）、状态组（openStates/closedStates/activeStates）、发布（earliestUnreleasedRelease）。
- 条件函数：结构（isTopLevel/isSubWorkItem/hasChildren/blockedBy/blocks/childOf/parentOf/linkedToAny/linkedToAll/linkedToAnyRecursive[depth≤10]）、aggregate("children|self","estimate|worklog","sum|avg|min|max|count","> n")（仅 points 估算计入，worklog 单位分钟）、hasNoAssignee/hasNoLabel/isOverdue、评论/链接/附件系列（hasComments(">= 3")/commentContains/lastCommentBy…）、worklog 系列、votedBy/stateChangedBy/resolvedBy、moduleMatch/releaseMatch（正则大小写敏感默认、≤200 字符、(?i) 可关）。
- 编辑器引导输入；**Plane AI 可用自然语言生成 PQL**（需开启 Plane AI）。
- 适用范围：工作项/周期/模块/视图/团队空间工作项/工作区视图。

### recurring-work-items.md（周期性工作项，Business）

- 项目设置→Execution→Recurring work items；项目 Admin 与 Contributor 可建。
- 模板=类型/标题/描述/状态/优先级/负责人/标签/模块；排期：开始日期（不得早于今天）、可选结束日期、重复间隔 Daily/Weekly/Monthly（月末取当月最后一天）/Yearly（处理闰年）/Custom（每 1-30 天|周|月|年）。
- 执行：每 15 分钟检查，**在项目时区的 00:05** 以排程创建人身份创建；改项目时区后下一次已排程的照旧、之后按新时区；模板失效（如工作流不允许该状态）该次记失败、通知排程创建人、继续下一轮。
- 编辑只影响未来实例；无暂停开关（只能设结束日期或删除重建）；有 Activity 运行日志。

### drafts.md（草稿）

- 不自动保存草稿；关闭创建弹窗有内容才询问；草稿私有；可手动 Draft a work item；操作：编辑/复制/移入项目（移入后才通知相关人员）/删除（不可恢复）。
