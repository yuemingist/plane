# 04. 模块（Modules）与视图（Views）

> 抓取日期：2026-11-14｜来源：docs.plane.so/core-concepts/modules、/core-concepts/views｜对应 F-ID：待 R1 映射

## 定义

- 模块：项目内按目标（功能/发布/活动）分组的工作项集合，有自己的负责人、成员、日期与进度。**模块仅存在于项目内，没有工作区/团队空间级模块视图**。
- 视图：保存的过滤器+布局+显示选项+排序组合，是"镜头"不改数据。三个层级：项目视图、工作区视图（表格式布局）、团队空间视图。

## Modules 摘要

- 新项目默认关闭（Features→Modules，项目 Admin）；模板创建的项目取模板设置。
- 创建：Add Module 或 `N,M`；标题必填 ≤255 且**项目内唯一**；日期单选范围（开始+截止）；Lead 与 Members 来自项目成员；负责人/成员身份不改变权限。
- 模块状态 6 个（手选，与工作项状态无关）：Backlog（默认）/Planned/In Progress/Paused/Completed/Cancelled；完成工作项不自动改模块状态。
- 加项：模块内 Add work item / Add existing；或工作项 Modules 属性（可多模块，须同项目）；归档模块不可加项但可移除项。
- 详情面板：Properties / Progress（x of y done + 各状态组条 + Overdue/Blocked 计数）/ Breakdown（State/Assignees/Labels/Priority，记住上次标签页）/ Links（URL+标题，记录添加人时间）。
- 进度口径：Completed 项 ÷（总数-取消项）；归档项不计。
- 三种布局：List（默认）/Gallery/Timeline（Admin 拖任意模块，Contributor 拖自建模块改日期）。
- 排序：Name/Progress/工作项数/Due date/Created date/Manual（升降序）；过滤：Favorites/Status/Lead/Members/Start/Due date（预设 1 周-2 月+自定义）。
- 归档：仅 Completed/Cancelled；归档移出主列表并从所有人收藏移除；恢复无确认；归档前不可编辑。
- 删除：Admin 任意，Contributor 自建；工作项保留但失去模块关联；不可撤销。
- 导出（Pro）：CSV/Excel/JSON 遵循当前过滤器；Commenter/Guest 无导出权限。
- 权限：Admin 全部；Contributor 创建/加减项/导出，编辑/归档/删除仅自建；Commenter 查看与收藏；Guest 无访问。

## Views 摘要

- 项目视图：随项目功能默认开启，支持全部布局；创建入口 Views→Add view 或工作项里 Save View。
- 工作区视图：跨项目过滤；**四个内置不可删视图：All Issues / Assigned to Me / Created by Me / Subscribed**；表格（spreadsheet）布局呈现。
- 访问级别：Public（默认，项目成员可见）；Private（**Pro**，仅创建者可见，只有 owner 可改回公开，项目 Admin 也不能越权查看）。
- Lock view（Pro）：创建者锁定后任何人（含其他管理员）不可编辑/改名，只能创建者解锁。
- Publish view（Pro）：生成公开链接（无需登录）；可配置访客是否可评论/反应/投票及可用布局；随时可下线。
- Share view（Business）：按人共享 View/Edit 两档；owner 与持 Edit 权者可再共享；成员被移出项目时共享自动撤销；**整表替换式更新**（不能只加删一人）。
- 导出（Pro）：CSV/XLSX/JSON；用当前会话未保存的过滤器；项目视图导出限本项目、工作区视图跨全项目；后台执行在 Exports 下载。
- 复制：Duplicate 前缀 Copy of；删除不影响工作项。
- 收藏：星标进侧栏 Favorites。
