# 13. 工时跟踪、客户管理、发布（Releases）、模板（Templates）

> 抓取日期：2026-11-14｜来源：docs.plane.so/core-concepts/issues/time-tracking、/customers、/releases、/projects/project-releases、/templates/\*（3 页）｜对应 F-ID：待 R1 映射

## Time Tracking（Pro）

- 项目 Admin 开启（Features→Time tracking）；Admin/Contributor 可记工时；Commenter/Guest 不可。
- 工作项上 +Log work：小时+分钟+描述；Tracked time 属性自动累加（不可直接编辑）。
- 编辑/删除：活动流条目菜单；Contributor 仅自己的记录；项目 Admin 任何人。
- 工作区报表：Workspace settings→Worklogs；按用户/项目/日期范围过滤；下载 Excel/CSV。
- PQL 侧：hasWorklogs/workLoggedBy/workLoggedBetween/aggregate("self|children","worklog","sum",…)（分钟）。

## Customers（Business）

- 工作区级开关（Workspace Settings→Customers）。
- 客户档案默认属性 9 项：Customer name/Description/Email/Website/Employees/Industry/Stage/Contract status/Revenue；可加自定义属性。
- 客户请求（Requests）：客户档案内建 request（名称+描述+来源链接 source links）；Link work items 把工作项挂到请求；工作项侧栏出现 Customers 字段（多个客户/请求；Admin 可悬停看客户详情）。
- 工作项可被多个客户请求关联；删除客户档案的规则同常规实体菜单（Edit/Copy link/Delete）。

## Workspace Releases（Business）

- 工作区 Features→Releases 开启；侧栏 More 下，可固定。
- 名称**全工作区唯一（含项目发布）**；可选描述/Target date/Lead/Tag（版本标签如 v2.3.0，单个）/Label（多个）；标签与 Label 目录在工作区 Features→Releases 管理。
- Scope：跨项目搜索加工作项；一项可属多个发布；不加项目/负责人/状态；列表/看板/表格可内联改 Releases 属性；两套发布共存时选择器分开 Project/Workspace releases。
- 状态机：Unreleased→Released（Release now：未完成项默认 Transfer unresolved work items 到另一未发布发布，或 Ignore）→Cancelled；完成全部项不自动 Released；取消保留 scope 不改项状态。未完成项定义=Backlog/Unstarted/Started。
- 进度=Completed ÷（总数-取消）；Overview 有 Activity；Scope 五种布局（含时间线）。
- Changelog：富文本自动保存，发布前后皆可写。
- 权限：Owner/Admin 建/改/发/删；Member 可见；Guest 不可；能编辑工作项者皆可挂/摘发布。

## Project Releases（Business）

- 项目 Features→Releases 开启（可独立于工作区发布开启）；仅本项目工作项；其余字段/状态机/Release now/changelog/进度与工作区版一致；目录在项目设置管理。
- 权限：项目 Admin 建/管；Contributor 可见+可通过工作项属性挂/摘；工作区 Admin 亦可管理。
- PQL：release 字段+earliestUnreleasedRelease()/inNextRelease()/releaseMatch()。
- Webhooks：里程碑/发布相关事件经 workitem.updated 等（项目发布与里程碑事件走 webhook）。

## Work Item Templates（Pro）

- 项目设置（或工作区设置）→Templates→Create template→Work Item template。
- 模板内容：名称/描述/标题格式/描述/属性（标签/负责人/模块等）/**可选子工作项集合**。
- 使用：创建工作项时模板图标选择；或设置页 Use template 直接开创建表单。

## Project Templates（Business）

- 工作区设置→Templates；捕获内容表：Basics（名称/描述/网络/lead/默认指派/logo/封面/时区）、Properties（优先级/起止/项目状态）、Features 开关集（默认开：cycles/modules/views/pages；其余关）、Automations（归档/关闭周期）、工作结构（状态/标签/工作流/估算/类型/epics）、内容（成员/intake/里程碑/模块/周期项/自动化/**启动工作项**）。
- 使用：创建项目时 Pick a project template；模板 lead 也会成为项目管理员；创建者成为管理员；后台复制内容。
- 菜单或有 Publish to Marketplace（跨工作区共享）。

## Page Templates（Pro）

- 工作区或项目设置→Templates→Page template；空页面时 Choose from template；有内容后按钮消失；Use template 从工作区设置建到 Wiki、从项目设置建到项目。
