# 20. 自托管（Self-hosting）与版本/设备

> 抓取日期：2026-11-14｜来源：developers.plane.so/self-hosting/_（84 页，此处摘关键 12 页）、docs.plane.so/devices/_、/support/\*｜对应 F-ID：待 R1 映射

## 版本与许可（self-hosting-101 / editions-and-versions）

- 三个自托管版本：**Community**（AGPL v3.0 开源=CE 本项目底座；功能=Cloud Free 档）/**Commercial**（闭源，含每工作区 12 席 Free 档，license key 解锁 Pro/Business/Enterprise）/**Airgapped**（离线许可，仅 Enterprise Grid，售前对接）。
- 版本=代码库（三套各自发版）；计划=license 解锁的功能集；Cloud 是新功能首发试验田→Commercial 次之→Community 最后。
- AGPL 实务边界：内部使用/内部修改 OK；对外托管服务需公开修改；嵌入商业产品需合规或购商业授权。
- Cloud vs 自托管对比表（迁移仅支持 Cloud→自托管方向）：审计日志/SCIM/高级认证在 Cloud 为 Business Plus，自托管按计划提供。
- 发布历史：all-releases 页列出商业版 1.0.0 起全部版本与 release notes（对追赶节奏判断有直接价值）。

## 架构（plane-architecture）

- 前端服务三件套：Web（主应用）/Space（公开发布）/Admin（实例管理）。
- API server：API（REST 核心）/Worker（RabbitMQ 异步任务）/Beat worker（定时任务）/Migrator（升级时跑一次 schema 迁移）。
- 支撑服务：Real-time collab（实时协作）/Integrations+importers（silo）/Plane embeds/Intake 服务/Monitoring。
- 基础依赖：PostgreSQL/MinIO/OpenSearch/Redis/RabbitMQ；可接托管服务（RDS/Cloud SQL/S3/GCS）。
- 集成外联：GitHub/GitLab/Slack 等。

## 部署方式（methods/\*）

- Overview：Docker Compose（中小团队）/Kubernetes Helm（生产）/Podman Quadlets/Docker AIO（单容器，仅评估）/Docker Swarm/Coolify/Portainer/一键云；商业版另有 install-methods-commercial 专用 Compose/K8s 指南。
- Airgapped：requirements（硬件/网络拓扑）+Docker/K8s 部署+私有 registry 镜像克隆。
- FIPS 变体：FIPS 强制主机上的 Enterprise 部署与镜像清单。
- 下载指定版本的 compose 配置 zip（download-config）。

## 治理配置（govern/\*）

- Instance admin & God mode：`/god-mode` 实例管理路由；General（实例名/ID/遥测开关/客服聊天开关——关遥测自动关聊天）/Email（SMTP）/Authentication（启用 SSO/OAuth 方式、唯一码与密码登录、是否允许无邀请注册）/Workspaces（全实例工作区列表、创建、**禁止他人创建工作区**开关；注意：工作区删除暂不支持）/User management（跨工作区用户、实例管理员邀请）。
- 环境变量总表（environment-variables）与 FILE_SIZE_LIMIT/ALLOW_ALL_ATTACHMENT_TYPES 等产品级行为挂钩。
- 认证方式：GitHub/Google OAuth、OIDC/SAML/LDAP、session expiry（god-mode）；密码重置；reverse proxy（需转发 WebSocket upgrade 头——否则页面实时同步失效）、SSL、自定义域名、私桶、外部 secrets、高可用/PDB/非 root K8s、AWS workload identity。
- Plane AI 配置：configure-plane-ai + embedding 模型（自建 OpenSearch embedding）；advanced search。
- 敏感数据扫描服务（配套 16 域）、邮件服务 DNS（intake email 依赖）、SMTP（SES/M365）、可观测性（OpenTelemetry/observability stack/signals）。
- 集成服务端配置：GitHub/GitLab/Bitbucket/MS Teams/Sentry/Slack 的自托管应用注册（产品侧集成的前置条件）。

## 运维（manage/\*）

- 升级（upgrade-plane 与 0.13→0.14 迁移专页）、备份恢复（backup-restore）、健康检查、日志查看、实例用户管理、实例迁移（换机，license delink 配套）、社区版→商业版升级（upgrade-from-community）、社区→airgapped、prime-cli、license 管理总览（检查频率/离线宽限/出网内容/席位口径）。
- 故障排查四页：installation/cli/license/storage errors。

## 遥测（telemetry）

- 匿名用量数据（实例 ID/工作区与成员计数/项目/工作项/周期/模块/评论计数/版本号/性能数据）；唯一 PII=实例管理员姓名邮箱（升级与安全通知）。
- God Mode→General 一键关闭；关遥测同时关闭应用内客服聊天。

## 设备端（docs.plane.so/devices）

- Desktop（macOS/Linux，Electron 41；自托管需商业版 ≥v3.0.0）：浏览器式标签/多窗口/dock 未读徽章/深链/自动更新；登录支持密码/魔法码/OAuth（Google/GitHub/GitLab/Gitea，回调 URI 需在 God Mode 登记）；**SAML/OIDC/LDAP 暂不支持**。
- Mobile（iOS 14+/Android 10+；商业版 ≥v1.12.0；全计划含 Free）：底部三标签 Home/Inbox/Search+悬浮创建按钮；产品磁贴（Projects/Wiki/Plane AI "Pi"）；小部件可编排；编辑器无 `/` 菜单与 AI。
