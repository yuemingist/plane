# 09. AI（Plane AI / Agents / Memory / MCP）

> 抓取日期：2026-11-14｜来源：docs.plane.so/ai/\*（13 页）｜对应 F-ID：待 R1 映射

## 定义

Plane AI 是内嵌全产品的 AI 层（Pro，自托管商业版需先配置 AI 服务）；基于工作区真实数据回答、创建更新、生成图表、起草页面、查重、推荐标签、自然语言过滤。Guest 完全不可用。

## plane-ai.md 摘要

- 开启：Workspace Settings→Plane AI→Turn on AI；Guest 不可用。
- 三模式（安全模型）：
  - **Ask**：只读问答；数据面=工作项全属性/项目/周期/模块/视图/团队空间/倡议/页面全文/成员/Plane 文档/（开启时）网络。
  - **Build**：先展示动作卡片计划，逐条确认后才执行；可单条改/取消。
  - **Autopilot**：跳过确认直接执行（需计划与配置显式开启）。
- 上下文：@ Add context 选项目或全工作区；可关闭工作区上下文加速；@mention 具体实体（工作项/项目/周期/模块/页面/状态/视图/团队空间/倡议）实时取最新数据。
- 网络搜索：Globe 开关；仅 OpenAI/Anthropic 模型支持（OpenAI 走搜索模型、Anthropic 走工具）；自托管模型不支持。
- 澄清机制：意图不明时 AI 反问候选解释而不是猜测。
- 图表：聊天内直接生成 Bar/Pie/Line/Stacked bar 四种。
- 周期指标：summary/scope changes/by state/by assignee/by priority/burndown/工作项清单。
- Build 可创建更新：工作项（全属性/评论/工时/关系/子项）、周期、模块、页面、标签、状态、估算、Intake、Stickies、倡议、团队空间。
- 语音输入（需管理员开启+服务端转写 key）；文件上传（需云存储配置）。
- 模型切换：对话中随时切换；默认 GPT-5.4；可用 GPT-5.2/Claude Sonnet 4.6/4.5；后台轻量任务（标题生成/查重/过滤转换）走小模型不受选择影响。
- 语义搜索用独立 embedding 模型（不可选）。
- 访问边界：不能访问非本人私有页面、非成员工作区、未接 MCP 的外部系统。
- 约束：Autopilot 需计划开启；模型列表由服务端配置决定。
- 页面内 AI（Business）：页顶提示词输入流式写入；**逐块 proposal 接受/拒绝**（快捷键 Cmd+Opt+Enter/Backspace）；选中文本改写五动作+语气（默认/专业/随意）；AI block。
- 工作项编辑器：I'm feeling lucky 一键生成描述（标题太空报错）；描述 AI 自定义提示（有第三方共享告知）。
- 查重：创建时自动向量查重，最多 5 个候选，可标 duplicate 或丢弃；全程自动不可手动触发。
- 标签预测：停顿约 1.5 秒后出现建议条（需项目建标签权限）。
- 会话管理：历史/星标/搜索/重命名/删除（不可恢复）；Convert to Page；点赞点踩。

## plane-ai-credits.md（AI 点数，Pro）

- 双预算：**个人月度额度**（chat/页面/描述/PQL 过滤/查重/标签建议/语音/网页搜索/与 agent 聊天）与**工作区 agent 共享池**（agent 各类运行、agent 网络搜索/记忆更新/提示建议）。规则：人触发→个人额度；agent 干活→工作区池。
- 每月 1 日 00:00 UTC 重置；不结转。
- 80% 警示 Nearing limit；100% 后**进行中的请求完成，下一个拒绝**；agent 池耗尽则新 run 不启动、进行中 run 立即中止。
- 单 agent 上限 Max credit usage（自托管显示 Max token usage）；需同时满足 agent 上限与工作区池。
- 自托管：自带 provider key，按 token 记录用量（无百分比）。

## ai-usage.md

- Usage 屏：月度用量条（Day 17/30 · Resets …）+本周/今日；状态 pill；趋势图 Week/Month。
- Analytics 屏：维度分解——Personal: Models/Features/Projects；Workspace（Admin/Owner）: Users/Agents/Models/Features/Projects；Features 枚举 Chat/Pages/Work items/Queries/Duplicates/Labels/Voice/Web search/Agents；CSV 全量导出。

## ai-skills.md（技能）

- 可复用指令存为 `/name` 斜杠命令；三个作用域：Personal（自建自用）/Workspace（Admin 建全工作区）/System（内置不可改）。
- 变量 `{{name}}` 自动识别；可插入 Plane 实体变量（work item/project/workspace/initiative/cycle/module/view/teamspace/page/assignee/priority/due date/state）。
- 名称作用域内唯一（小写连字符）；指令 ≤8000 字符；个人技能仅对本人启动的 run 生效。

## memory.md（记忆，Pro，默认关）

- 四类记忆：Personal（5000 字符，仅本人可见可编辑）/Project（8000，项目 Admin）/Workspace（12000，工作区 Admin）/Agent（5000，Admin+创建者）。
- 读取顺序：个人→项目→工作区；越具体越优先；agent 永不读个人记忆。
- 写入：个人记忆在 ≥3 条消息的会话后或分享关键事实时更新；项目/工作区记忆可 Generate memory 生成（消息：Memory updated/unchanged/kept as-is/nothing to synthesize/off）；agent 记忆来自与人的对话。
- 更新不把记忆缩到一半以下（除非要求遗忘）；消耗工作区点数。

## agents/\*（4 页，Pro）

- Agent=工作区里的常驻助手：独立身份（成员列表 Agents and apps 下、评论署名、出现在 @mention 与指派人列表；**不出现在任何 lead 选择器**）。
- 组成：Instructions/Triggers/Scope & access/Skills/Advanced（凭据与点数上限）。
- 手柄：名字生成 @handle，全 Plane 唯一（冲突加后缀）；删除释放 handle。
- 创建：模板 Triage Bot/Standup Summarizer/Spec Writer；Write with Plane AI 可从描述生成整套配置（≤4000 字符提示）。
- 触发器：
  - 直接触发（开关型）：被 @mention（回复同线程续同一 session）/被指派为 assignee。
  - 事件（5 种，可加过滤器 Basic/PQL）：work item created/updated/state changed/assignee changed/comment added；**agent 自己的变更不触发事件触发器**（防互聊）；直接触发例外。
  - Schedule（可多个）：Fixed（Daily/Weekly/Monthly+时间+时区）或 Cron（五字段+时区校验）。
  - Chat：无需触发器；会话私有、不入 Sessions 与统计。
- 过滤器维度：Projects/Type/State Group/Assignees/Priority/Label/Start/Due date；无过滤器的事件触发器需二次确认。
- Scope：项目（Selected/All，互斥）；授权=bot 用户以读写身份加入项目；Web access 开关+Trusted URLs（只看域名）；Connectors 按 agent 挑工具。
- 凭据：Use connected tools as 每人自己的账户（默认）或统一创建者账户；**事件与计划运行恒用创建者凭据**；创建者未连接则 session 转 Needs Input。
- Sessions 状态机：Created→In Progress→(Needs Input)→Completed/Stopping/Stopped/Failed/Stale（无徽章）；sidecar 展示思考/动作/回应；回复完成/停止/失败/过期会话原地续跑；失败会话只能从评论线程重启。
- 统计：Total invocations/Cumulative success rate/Avg. credits used/Total credits usage。
- 权限：配置仅工作区 Owner/Admin；成员可查看/提及/指派；Guest 仅在其项目角色允许评论处提及。
- 停用/删除：停用移除 bot 用户与项目访问、停触发器、停聊天，但历史会话保留、既有 mention 线程回复仍可达；删除永久。

## mcp-server.md（对外 MCP）

- 托管端点 `https://mcp.plane.so/http/mcp`；OAuth 连接；以本人身份、本人角色权限读写；一连接一工作区。
- 能力：工作项 CRUD/评论/附件/链接/关系/子项/工时；周期/模块/里程碑；项目/状态/标签/类型/自定义属性；倡议；发布+changelog；客户；页面；Intake；支持 PQL。
- 未订阅计划的功能返回明确的"not available on your plan"。
- 客户端指南：Claude/Claude Code/ChatGPT/Codex/Cursor/VS Code/Windsurf/Zed/Antigravity；不消耗 Plane AI 用量。
- 自托管：本地 stdio 或自建服务器（见 mcp-server-self-host；商业版 Helm 内置于 /mcp 路径；社区版无 OAuth 应用注册，仅 stdio+PAT）。

## mcp-connectors.md（对内 MCP）

- 给 Plane AI 接外部工具：GitHub(Header PAT)/Sentry/Granola/Postman/PostHog/Evermuse/Intercom(OAuth 或 Header)。
- 每用户各自认证；凭据加密存储；OAuth 自动刷新；配置在 Workspace Settings→Integrations→Connectors。
- 会话内按需启用（仅 Build/Autopilot 模式可用连接器）；自定义连接器：Name+MCP URL+认证类型（None/Headers/OAuth）；改 URL/认证会使既有连接失效；仅创建者可改删。
