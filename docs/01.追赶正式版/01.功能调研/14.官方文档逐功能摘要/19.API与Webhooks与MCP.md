# 19. API、Webhooks、OAuth 应用与 MCP（开发者平台）

> 抓取日期：2026-11-14｜来源：developers.plane.so（dev-tools/\*、api-reference/introduction；每页 URL 加 `.md` 得 Markdown）｜对应 F-ID：待 R1 映射

## REST API（api-reference/introduction.md）

- REST、JSON；Base URL：Cloud `https://api.plane.so/`，自托管为实例域名；路径 `/api/v1/workspaces/{workspace_slug}/...`。
- 认证三式：
  - `X-API-Key`（个人访问令牌：Profile Settings→Personal Access Tokens，可设过期）。
  - OAuth Bearer（Plane App 的 user/bot token，按授权 scopes 限权）。
  - OAuth Bridge：直接用企业 IdP（Entra ID/ADFS/Okta）的 Bearer token，按邮箱匹配 Plane 用户。
- API 参考分域：assets/collection(页面集合)/cycle/customer/epics/estimate/idp-group-sync/inbox-issue/intake-issue/initiative/issue(工时 worklogs、评论、附件、活动、链接、关系)/issue-types/milestones/module/page/project/project-labels/release/state/sticky/teamspace/user/workspace-features/workspace-invitations 等；v1+V2 两版（987 个端点页，本文档不逐条展开）。
- OpenAPI：自托管开 `ENABLE_DRF_SPECTACULAR=1` 后暴露 `/api/schema/`（YAML/JSON）、Swagger UI、ReDoc；亦可离线 `manage.py spectacular` 导出。

## Webhooks（dev-tools/intro-webhooks.md）

- 工作区级（无项目级 webhook）；仅工作区 Owner/Admin 管理。
- **V2 现行、V1 已弃用**（继续投递但无 v2 字段；迁移=重建新 webhook）；v2 特性：点号事件名（`workitem.created`）、`delivery_id`+`event_id` 去重、`previous_attributes` 差异字段。
- 创建：标题+公网 Payload URL（拒 localhost/内网）+勾选事件（按 Projects/Cycles/Modules/Work items 等分组）+secret key（保存即下载 CSV，仅此一次；可重生成但旧 key 即刻失效）。
- 过滤：仅作用于工作项事件；Basic 可视化与 PQL 两种模式无损互切；投递时求值，求值失败=跳过该次投递。

## 构建 Plane App（dev-tools/build-plane-app/\*）

- OAuth 2.0，Beta；两种流：**Bot Token**（Client Credentials，自治型 agent/webhook，推荐）与 **User Token**（Authorization Code，代理用户）。
- 应用组成：OAuth 应用（Client ID/Secret）+Setup URL+Redirect URI+Webhook URL+API 集成。
- Scopes：资源级 `resource:read|write` 全家桶（projects._（含 features/members/states/labels/intakes/epics/cycles/pages/modules/work_items 及 comments/attachments/links/relations/activities/worklogs 细分、work_item_types/properties/options/values、milestones）、wiki.pages、customers._、initiatives、cycles、modules、teamspace、sticky、state、workspace 等）；应用注册仅 Cloud 与商业版（社区版无 OAuth 应用注册）。
- 事件信号载荷（dev-tools/agents/signals-content-payload）与最佳实践页面向 agent 类应用。

## MCP server（dev-tools/mcp-server、mcp-server-self-host、mcp-server-tools）

- 对外：`https://mcp.plane.so/http/mcp`（托管）或自托管三种方式：Docker Compose/商业版 Helm（内置 `/mcp` 路径，推荐）/独立 Helm；社区版仅本地 stdio+PAT。
- 工具清单页（mcp-server-tools）按资源分组列出全部工具与动作；支持 PQL 过滤。
- 详情见 09.AI 域 mcp-server 摘要。

## Plane Compose（dev-tools/plane-compose，CLI）

- 把项目当代码管理：`schema/`（features/类型/状态/工作流/标签/成员/模板）+`work/`（工作项/周期/模块/里程碑/页面）+`.plane/state.json`（本地映射，git-ignore）。
- 命令组：Safe（只读）/Confirm（改动前询问，--force 跳过）/Destructive；clone/pull/push/diff/validate/schema import|sync；Python 3.10+，`pipx install plane-compose`；PAT 或 OAuth 认证；文档版本 v0.5.2。

## OAuth Bridge（dev-tools/oauth-bridge）

- 允许应用直接拿企业 IdP token 调 Plane API；按邮箱匹配用户并沿用其权限；适合 SSO 环境免二次授权。
