# 08. 分析（Analytics）与仪表盘（Dashboards）

> 抓取日期：2026-11-14｜来源：docs.plane.so/core-concepts/analytics、/dashboards｜对应 F-ID：待 R1 映射

## Analytics 摘要

- 层级：工作区级（仅 Admin 角色可入，左栏）、项目级（Admin/Member，项目顶栏）、周期/模块级（对应视图顶栏 Analytics）。
- 六个分析页：
  - **Overview**：用户统计（总数/管理员/成员/访客）、项目数、工作项总数、活跃周期与 intake 统计。
  - **Projects（Pro）**：总数+on-track/off-track/at-risk 健康度；按项目状态分布；明细表（成员数/工作项/周期/模块/页面/视图/intake）；可搜索；CSV 导出。
  - **Work items**：总量+状态组分布；Created vs Resolved 面积图；自定义图表构建器（按优先级/负责人/状态/标签/周期维度切分）；CSV 导出。
  - **Cycles（Pro）**：总数按 current/upcoming/completed；周期完成度散点图（悬停显示各组明细）；表（lead/项目/时间线/完成率）。
  - **Modules（Pro）**：completed/in progress/planning/paused 汇总；进度散点；表。
  - **Intake（Pro）**：总量+accepted/declined/duplicate 分布；趋势图；项目分布表。
- 导出：每个视图 CSV 一键导出；**仅 Admin 角色可导出**。
- 交互图表：悬停 tooltip、即时上下文。

## Dashboards 摘要（Pro）

- 工作区级画布，由 widget 组成；只读镜头、实时重算；数据源=创建时选择的若干项目（可跨项目）+可选基础过滤器。
- 可见性：Public（默认，全工作区可见；仅创建者/工作区 Admin/Owner 可改删）；Private（**Business**，仅自己可见）。
- 编辑/视图两模式；Add widget→类型+模型→配置侧栏。
- **Widget 类型 × 模型**：
  - Bar：Basic/Stacked(Business)/Grouped(Business)
  - Line：Basic/Multi-line(Business)
  - Area：Basic/Stacked(Business)/Comparison(Business)
  - Donut：Basic/Progress(Business，固定按状态组算完成度)
  - Pie：Basic（细片合并 Other，阈值可配）
  - Number：单指标（不支持 estimate points——需用表格）
  - Work items statistics（Business）：Group by 11 维×Work item count/Estimate points；Max rows 1-100 默认 10；百分比/进度条色。
  - Smart Counter（Business）：Grid/Table 两种呈现。
  - Smart Gauge（Business）：按组完成度半环仪表（Completed 状态组为完成）。
  - Two dimensional table：一行一组+计数（固定工作项计数）。
  - Work items Table（Business）：逐行工作项列表；列 17 项可选（标识+名称+项目恒显）；每页 1-100 默认 10。
  - Assigned to you（Business）：自动按查看者解析"我的任务"；公开仪表板上无登录用户→显示空。
  - Work item type progress（Business）：按类型列出工作项及其子项完成度进度条（Linear/按状态组分段）；Show completed（把取消项计为完成）等选项。
  - Cycle progress bar（Business）：单周期快照（状态组分布/完成度/scope 变化/被阻塞数/已用天数/剩余天数/状态）。
  - Intake accepted vs declined（Business）：双时间序列（多线或堆叠柱）；绿=接受红=拒绝；pending/snoozed 不计。
  - Average time to accept and decline（Business）：决策耗时（天）趋势线或总数。
  - Intake breakdown（Business）：六个固定指标（In-app/Email/Form 量、Total accepted/rejected、Avg. time to decide）；Grid/Table；不受 widget 过滤影响。
  - Intake items ageing（Business）：未决策项 0-2/3-7/7+ 天环形图；色板 Modern/Horizon/Earthen；中心总数可关。
- Widget 配置：X 轴属性（State/State group/Priority/Assignees/Created by/Labels/Cycles/Modules/类型/Projects/四个日期+Day|Week|Month|Year 聚合）；Y 轴指标 8 种（Work item count/Estimate points/Pending/Completed/In-progress/Due today/Due this week/Blocked；**estimate points 需项目为 points 估算，否则为 0**）；Group by 二维细分；样式按类型；Widget 级过滤器叠加在仪表盘级过滤器之上。
