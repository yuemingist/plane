# 18. 公开发布（Space / Publish）

> 抓取日期：2026-11-14｜来源：docs.plane.so/core-concepts/deploy、/core-concepts/views（Publish view）、/pages/publish-and-export、/pages/report-page｜对应 F-ID：待 R1 映射

## 定义

Plane 的公开发布体系有三层：发布项目（Space 公开板）、发布视图（公开视图链接）、发布页面（公开页面）。自托管架构里由独立 **Space 服务**承载（见 19.自托管 architecture）。

## 发布项目（core-concepts/deploy.md）

- 仅项目 Admin 可发布（菜单 Publish project；须为成员且项目未归档）。
- 配置：Views 选要发布的布局（**List/Board 必选其一且不可去**；Table/Calendar/Timeline 随工作区可用性）；Allow comments / Allow reactions / Allow voting 三开关默认全关；至少选一个布局否则报错。
- 公开链接形如 `https://<host>/<space path>/issues/<anchor>`（anchor 唯一）；"Anyone with the link can access"；无需注册。
- 属性隐私表：公开可见=项目名/工作项 ID+标题+描述/状态+截止日期+优先级/评论/反应（含反应人名）/赞成反对票（含投票人名）；**不可见=附件/工作项链接/关系/周期与模块/项目设置/成员**。
- 评论：开启后访客可在公开板注册并评论；**团队在 Plane 内的评论默认不公开**，作者需手动 Switch to public comment。
- 投票：访客可对工作项 upvote/downvote。反应：预置表情。
- 可免费托管域名（free domain hosting）；可随时改发布设置或取消发布。

## 发布视图（views.md Publish 节，Pro）

- 项目视图可发布：Share 面板→Publish 开关→公开链接；可配访客评论/反应/投票与可用布局；取消发布链接立即失效；原视图不受影响。

## 发布页面（publish-and-export.md，Pro）

- 项目页与 Wiki 页可发布（团队空间页不可）；嵌套页连带发布/取消；归档即取消发布；公开页只读、不显示评论；访客可复制链接或举报。
- 举报体系见 06 域（report-page）。

## 受限工作项与公开面（联动规则）

- 工作项挂有任何 audience（即使 inactive）时**一律不出现在已发布视图**（work-item-security.md）。
- 公开板上的隐藏评论同样显示横幅（comments-moderation）。
