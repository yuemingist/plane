# 01. 工作项基础（Work Items）

> 抓取日期：2026-11-14｜来源：docs.plane.so（每页 URL 后加 `.md` 可得 Markdown）｜对应 F-ID：待 R1 映射

## 定义

工作项（Work item）是 Plane 中最小的工作单元。每个工作项必属于一个项目；周期、模块、视图、仪表盘、分析均围绕它组织。Plane 已把产品术语从 issue 统一改名为 work item（官方文档全站如此；CE 代码/语言包仍大量使用 issue，i18n zh-CN 译名"工作项"一致）。

## 覆盖页面（8 页摘要）

### work-items/overview.md

- 组成：ID（项目标识符+自增序号，如 WEB-142）、标题（必填 ≤255 字符）、富文本描述（自动保存+版本历史）、属性、类型、状态。
- 默认属性全集：状态/优先级/负责人/标签/开始与截止日期/估算/父项/周期/模块；开启相应功能后追加：里程碑、发布（Releases）、客户（Customers）、记录工时。
- 四种连接：父子子工作项（可跨项目）、关系 Relations（不影响日期）、依赖 Dependencies（影响排期，画在时间线）、关联页面 Linked pages（Pro）。
- 生命周期：创建（含 Intake/模板/周期性）→ 填属性 → 状态流转（全程记录活动+订阅通知）→ 到 Completed/Cancelled 后可归档（或自动化归档）→ 删除为永久。
- 查找入口：项目 Work items、Your Work、Views、Power-K（Cmd/Ctrl+K）。

### work-items/create-and-manage-work-items.md

- 创建：快捷键 `N,I`；Create more 开关可连续创建；标题必填 ≤255 字符；必填自定义属性未填不能保存。
- 关闭创建弹窗且有内容时询问"Save this draft?"→ 存为草稿（草稿私有）。
- 快速添加（Quick add）：仅输入标题回车，自动继承所在分组值（如看板列=状态、日历格=截止日期）。
- 复制（Make a copy）为 **Pro** 功能：同项目复制标题加 `(Copy)`；跨项目复制时状态改为目标项目起始状态、负责人/标签/周期/模块/估算清空、自定义属性值以文本追加进描述、父项清空、子项不复制；归档项复制出来是活跃项；副本与原件建立 Duplicate of 关系。
- 归档：仅 Completed/Cancelled 状态可归档；归档项只读（不能编辑/评论/投票/订阅），可随时恢复；项目菜单 Archives（快捷键 `G,R`）。
- 删除：永久，级联删除全部子工作项与附件；Admin 可删任意项，Contributor 只能删自己创建的。

### work-items/work-item-details.md

- 打开方式三种 peek：侧边 Side peek（默认）、弹窗 Modal、全屏 Full screen。
- Header 操作：工作流 Approve/Reject（待审批时出现）、投票（Up/Down，可看投票人）、订阅、复制链接、**Copy as prompt**（把工作项打包为 AI 编码工具提示词，可直达 Cursor/Codex/Claude Code）。
- 状态旁可显示"该状态停留时长"徽章（time in state，文档标记 TODO 未定档位）；里程碑超期时截止日期旁出警告图标。
- 侧栏分组：Details（父项/标签/估算/已记录时间）、Project structure（周期/模块/客户/里程碑/发布，随功能开关出现）、自定义属性；底部显示创建人/创建时间/更新时间/完成时间。
- 工具栏：加子项、依赖、关系、链接、附件、关联页面、客户请求、复制分支名。
- 子工作项：可跨项目；开启层级（Hierarchy）后仅允许父类型下层级的类型；删除父项级联删除子项。
- 关系类型（内置）：Relates to / Duplicate of / Implements / Implemented by（后两者需开启时间线依赖）；系统自动互加反向关系。
- 依赖类型（内置）：Blocked by / Blocking 常驻；Starts Before/After、Finishes Before/After 需开启时间线依赖；两工作项之间只能有一条依赖。
- 附件：单文件 ≤5MB（Cloud 付费计划 100MB；自托管由 `FILE_SIZE_LIMIT` 环境变量控制）；支持类型白名单（图像/文档/音视频/压缩包/Visio/3D/字体/代码数据等）；自托管可 `ALLOW_ALL_ATTACHMENT_TYPEers=1` 全放开。
- 关联页面为 **Pro**；Development 区块（分支/PR/commit 关联）为 **Pro**，代码链接规则：大写工作项 ID 出现在分支名/PR 标题或描述/commit 消息，支持 GitHub/GHE、GitLab/Self-managed、Bitbucket/Data Center。
- 活动区 7 个标签页：All / Activity / Comments / Updates（状态更新，On Track/At Risk/Off Track）/ Worklogs / Transition（每次状态停留时长）/ History（属性前后值）。
- 描述版本历史：点"Last edited by"查看、复制 Markdown、恢复。

### work-items/work-item-properties.md

- 默认属性表 + 只读系统属性（ID/创建人/创建时间/更新时间/完成时间 Completed on）。
- 规则：仅项目 Admin/Contributor 可被指派（Commenter/Guest 不可）；指派自动订阅；截止日期不得早于开始日期；已记录时间为合计只读。
- 自定义属性 10 种：Text/Number/Dropdown/Boolean/Date/Member picker/Release picker/Rich text/URL/Formula。

### work-items/custom-relations.md（Enterprise Grid）

- 工作区级自定义关系类型；三个字段：Title、Inward name（本端视角）、Outward name（对端视角）。
- 创建后全工作区项目可用；Workspace Admin 管理；编辑/删除即时全工作区生效。

### work-items/project-work-item-types.md（Pro）

- 开启后自动创建 Task（默认）与 Epic 两个类型；**开启后不可关闭（不可逆）**。
- Project Admin 管理；类型可设图标/颜色/是否可被选用；默认类型可切换且不可停用。
- 属性类型细节：Text 三格式（单行/段落/只读）；Number 可默认值；Dropdown 单/多选；Boolean 不可必填；Date 四种显示格式；Rich text 为 Business；Member picker 自动订阅被选人；Release picker 为 Business；URL；Cascading（级联，Enterprise Grid）2-4 级、逐级必填、选项删除需输入 Confirm、值移入描述防丢失。
- 切换类型：旧类型独有的自定义属性值转为描述文本，不可撤销；不能批量切换类型。
- 删除类型：已有工作项保留类型直到逐个改掉。

### work-items/workspace-work-item-types.md（Enterprise Grid）

- 类型在工作区定义（Workspace Admin），项目导入使用；类型名工作区唯一；新类型默认 inactive。
- Rollout 两种：Import（默认，项目手动导入）/ Mandatory（立即进所有项目且项目不可移除；改回 Import 不会从已有项目撤除）。
- 属性公共设置：标题类型内唯一、不得用保留名 state/due date/cycle/modules；Mandatory 会清掉默认值；Boolean/Formula/只读 Text 不可必填；仅 Number/Dropdown/Member picker 支持默认值；Active 开关隐藏不删数据。
- 已有值后属性类型/单多选/选项配置被锁定不可改。
- Contexts（上下文）：同一属性可按"项目×类型"覆盖必填/默认等设置，取最具体匹配。
- Formula（Enterprise Grid）：只读计算属性，`{{field}}` 引用，运算/比较/&拼接/IF/ROUND/ABS/UPPER/LOWER/LEN/CONCAT/TODAY()/NOW()；空值传导为空；除零显示错误态；不可必填、不可过滤分组。
- Hierarchy（层级，不可逆）：Level 0 默认叶子层；拖拽配层；启用后新建/子项/改类型/UI/批量/导入全链路拦截非法嵌套；改层若破坏现有父子关系需输 confirm，破坏的父链被移除并记录活动。

### work-items/work-item-security.md（Enterprise Grid，ALPHA 标记）

- Audience（受众）= 命名的可见名单，可含工作区角色/项目角色/指定成员；挂到类型（整类受限）或单个工作项（覆盖类型受众）。
- 工作区 Owner/Admin 永远可见且不可移出受众；被指派人与订阅者即使不在受众也可见（安全反模式，文档明确警告）。
- 空受众=仅 Owner/Admin+指派与订阅者可见；受众 Active/Inactive，停用即解除限制。
- 受限项从列表/看板/周期/模块/仪表盘/页面/搜索/通知/邮件中全部隐藏；邮件发送前二次校验；已发布项目中带受众的项一律不出现。
- 复制受限项会带上受众；权限点：View/Create/Edit/Delete Audiences（可入自定义角色）。

## 权限速查

| 动作                | 权限                                      |
| ------------------- | ----------------------------------------- |
| 创建/编辑/复制/归档 | 项目 Admin 或 Contributor                 |
| 删除工作项          | Admin 任意；Contributor 仅自己创建        |
| 切换类型            | 能编辑该项者；不支持批量                  |
| 拖时间线/依赖       | Owner/工作区 Admin/项目 Admin/Contributor |
