## 官方文档里新发现、此前调研（10-12 号文档）未覆盖或结论不同的规则 Top 5

1. **Workflows 已下沉为 Business 档功能**：默认工作流+每状态"允许新建"开关+流转"by 成员名单"；审批流、前置校验/后置脚本、多工作流按类型与 governance mode 才是 Enterprise Grid。此前资料多把 workflow 归为 EG 独占，档位判断需修正（12 域文件）。
2. **AI 双预算点数体系**：个人月度额度与工作区 agent 池分离、每月 1 日 UTC 重置、80% 警示、超额拒新请求但放行进行中请求；自托管按 token 记账。此前调研只覆盖"AI 功能列表"，无配额与状态机（09 域文件）。
3. **审批状态机与 Agent 会话状态机**：工作项待审批时详情页出现 Approve/Reject；agent session 有 8 态（Created/In Progress/Needs Input/Completed/Stopping/Stopped/Failed/Stale），Needs Input 靠评论回复续跑、失败会话只能从线程重启（09、12 域文件）。
4. **审计日志为 append-only + 密码学链式防篡改**，查日志/导日志本身也入日志；项目级日志是同一底表的工作区切片。此前调研只记"有 audit logs 功能"，无完整性机制与事件分类清单（16 域文件）。
5. **页面嵌套/集合/Wiki 的继承规则簇**：嵌套页继承父页公私/共享/发布/集合/归档/锁定七类设置且联动；恢复旧版本会把"当时已删除的嵌套页复活、其后新建的嵌套页删除"；集合可见性创建后不可改。这些边界规则在 UI 对比中不可见（05、06 域文件）。
   （另值得注意：发布项目中团队评论默认不公开需作者手动切公开；批量复制 ≤1000；订阅视图共享是整表替换式更新；workspace URL 创建后不可改。）
