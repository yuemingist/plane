# 03. 周期（Cycles）与里程碑（Milestones）

> 抓取日期：2026-11-14｜来源：docs.plane.so/core-concepts/cycles、docs.plane.so/projects/milestones｜对应 F-ID：待 R1 映射

## 定义

- 周期：按时间段（如两周 sprint）组织工作项；周期按"时间"组织，模块按"目标"组织。一个工作项同一时刻只属一个周期。
- 里程碑：项目内的检查点（如 Beta 发布、安全评审），围绕目标日期组织；一项工作项同时只属一个里程碑且须属本项目。

## Cycles 摘要（docs.plane.so/core-concepts/cycles.md）

- 新项目默认关闭；项目 Admin/工作区 Admin 在 Features→Cycles 开启；同页还有 Parallel cycles、Auto-schedule cycles、Manual cycle advancement 三个子开关。
- 创建：侧栏 Cycles→Add cycle，或 `N,C`（弹窗头部可切目标项目）；标题必填；开始+截止日期必须成对存在或都没有（没有日期=草稿）。
- **默认同项目周期日期不得重叠**（与活跃/即将开始的周期重叠时提示，可去日期存草稿）；Parallel cycles（Enterprise Grid）开启后可重叠，每个活跃周期独立进度与卡片；工作项加新周期=移动；关闭开关后已存在的重叠保留、新建/改日期重新校验。
- Auto-schedule cycles（Business）：标题基名+自增编号；周期长度 1-30 周；冷却期天数；起始日（不可过去）；未来周期数 1-3；**Auto-rollover work items**（周期结束时把 Backlog/Unstarted/Started 项移入下一周期，Completed/Cancelled 留下）。保存后字段只读需 Edit 修改；保存只补缺不重命名/重排已有周期。
- 周期状态由日期推导：Draft（无日期）→Upcoming→Active→Completed（到期或提前完成）。徽章显示 In progress 或剩余天数。
- 提前开始/提前完成（Pro）：Start cycle 把开始日期改为今天；Complete cycle 把截止日期改为今天；若有未完成项可选"留在本周期"（默认）或"转移到某个 upcoming/draft 周期"；**完成后不能重新开始**；完成后不可编辑、数据冻结供分析。Manual cycle advancement（Enterprise Grid）把这两个按钮常驻显示。
- 未完成项转移：完成周期横幅下 Transfer work items → 选活跃/upcoming/draft 周期；只移 Backlog/Unstarted/Started；每周期只能用一次。
- 进度：详情面板燃尽图+按负责人（默认标签页）/状态/标签分解；**Progress charts（Pro）**：Burn-down/Build-up × 工作项/估算（points 或时间）；理想线为直线；领先绿/落后红；指标含 Today's ideal Pending/Done、Pending、Started、Scope（除 Cancelled）、Done、Unstarted、Backlog；显示排除的取消项数与 scope 变更次数。
- 工作区侧栏 Cycles→Active cycles 页（Pro）：跨项目活跃周期卡片（并行周期每周期一卡）。
- 归档：仅已完成周期可归档；项目菜单→Archives→Cycles 恢复（无确认）。
- 删除：Draft/Upcoming/Active 可删；Admin 任意，Contributor 仅自建；不可撤销，工作项保留但失去周期关联。
- 导出（Pro）：菜单 Export→CSV/Excel/JSON，遵循当前过滤器；下载走工作区 Exports。

## Milestones 摘要（docs.plane.so/projects/milestones.md，Pro）

- 新项目默认关闭；项目 Admin/工作区 Owner/Admin 开启（Features→Milestones）；开启后项目 Overview 出现 Milestones 标签页；关闭不删数据，仅隐藏入口与属性。
- 创建：Overview→Milestones→Add milestone；标题必填 ≤255、**项目内唯一且大小写敏感**；描述支持格式/提及/图片/文件；目标日期可选。
- 加工作项：Link work items 搜索本项目未属其他里程碑的项（≤20 条结果；草稿/归档/未接受 intake 项不出现）；或在工作项侧栏 Project structure→Milestone 选择（可 No milestone 移除——里程碑页面本身无移除按钮）；支持批量设置；子项需单独关联。
- 进度=已完成项数 ÷（总数-取消项数），取整百分比；无项或全取消显示 0%；图标灰(0%)/琥珀(进行中)/绿勾(100%)。**目标日期过了不标记 overdue**。
- 目标日期变更不重排工作项；工作项截止日期晚于里程碑目标日期时详情页出警告图标（仅详情页，列表/看板/表格/时间线无）。
- 项目时间线上有目标日期的里程碑显示为虚线竖标记（多里程碑同日合一标记，琥珀色）；悬停显示名称/进度/项数（含取消项）。
- List/Board 可按 Milestones 分组（组按目标日期排序，无项入 None 组；组内新建自动归属；**分组时不能拖动工作项**）；Table 可加里程碑列；可按里程碑过滤与 PQL milestone 字段。
- 跨项目移动工作项对话框有 Milestones 段：映射到目标项目里程碑或留空移除；目标项目未开启里程碑则数据被移除。
- 自动化（Business）：Change property 动作可指派/移动/移除里程碑（仅本项目、不可归档的里程碑）。
- Webhooks：里程碑 created/updated/deleted 事件；随项目归档/恢复计为 update；API 可全量管理。
- 权限：查看（Admin/Contributor/Commenter）；创建编辑删除与链接项（Admin/Contributor）；开关功能（Admin）；Guest 无。自定义角色有 View/Create/Edit/Delete Milestones（Project Configuration 组）。
- 删除不可撤销，工作项保留并记录活动。
