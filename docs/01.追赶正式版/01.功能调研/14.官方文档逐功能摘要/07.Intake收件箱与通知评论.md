# 07. Intake、收件箱与通知评论

> 抓取日期：2026-11-14｜来源：docs.plane.so/intake/*、core-concepts/intake、communication-and-collaboration/*｜对应 F-ID：待 R1 映射

## 定义

- Intake：外部请求进入项目的缓冲区。所有 Intake 项统一处于系统 **Triage** 状态（不属于项目五状态组）。接受时可选择目标状态（默认项目默认状态）。
- Inbox：应用内通知中心；Notifications：应用内+邮件+移动推送三通道体系。

## Intake 四页摘要

### intake/overview.md

- 三个渠道：Intake In-app（Guest 在应用内提交）/Intake Forms（公开表单）/Intake Email（专属邮箱）。
- 项目级功能默认关闭；项目 Admin 开启 Intake 总开关，再按需开 Forms/Email。
- **Intake responsibility（Business）**：指定一名负责人，所有新 Intake 项自动指派给他并通知；仍可再改派。
- 拒绝/标记重复的项保留在 Intake（Triage 状态）供追溯。

### core-concepts/intake.md（In-app）

- Guest 可建 Intake 项：可设优先级/负责人/标签/截止日期；状态恒 Triage。
- 管理动作：Accept（弹窗可改属性后 Add to project）/Decline（项目内变 Cancelled）/Snooze（选日期，移出 pending，可在 Filters→Open 下看到，可取消暂停）/Mark as duplicate（选择项目内重复项，Declined+Duplicate 标记，项目内 Cancelled）。
- 仅 Admin 可在入工作流前删除 Intake 项。
- 视图：Open（Pending+Snoozed）/Closed（Accepted+Declined+Duplicate）两标签；过滤 8 项、排序（创建/更新/ID 升降）；富文本描述+活动+评论+表情反应；🔼🔽顺序审阅。

### intake/intake-forms.md（Business）

- 开启生成唯一 URL，可 Renew 换新 URL（旧 URL 失效）。
- 提交者填姓名/邮箱/工作项详情；进入 Intake（Triage）。
- 自定义表单：基于工作项类型构建，勾选该类型的自定义字段；每个自定义表单独立 URL；可 Preview。

### intake/intake-email.md（Business）

- 开启生成专属邮箱地址（可 Renew）；邮件主题=标题、正文=描述、附件保留。
- 自托管需先配 DNS/邮件服务（developers.plane.so/self-hosting/govern/configure-dns-email-service）。

## inbox.md（收件箱）

- 两标签：All / Mentions，各自未读计数；侧栏图标红点提示。
- 卡片操作：已读/未读切换、归档（Show archived 可见）、Snooze（1/3/5 天、1/2 周、自定义时间）。
- 过滤：Assigned to me / Created by me / Subscribed by me；三态显示开关（未读/归档/已暂停，互斥单选）。
- 卡片内容：行为人头像（截止日期提醒=铃铛）、一句话动作、项目标识+序号+标题、相对时间、未读点、暂停提示 Till {date}。
- **Stacked notifications（Pro）**：按工作项聚合一张卡（多人头像+未读数+最新时间）；悬停展开逐条预览；点开全部标已读并在全页视图高亮相关活动 5 秒；批量已读/归档/暂停。

## notifications.md

- 邮件偏好（Profile Settings→Notifications，全工作区生效）：Property changes / State changes（子开关 Issue completed）/ Comments / Mentions。**偏好只控邮件；Inbox 永远全收**。
- 触发事件表：创建/任意字段更新/评论增改删/链接增改删/附件增删/关系增删/删除/提及/工作项 update 发布/截止日期临近提醒——均通知。
- 通道：Inbox（全量不可关）/Email（**5 分钟批量合并**）/Push（可关）。
- 通知对象：订阅者+全部负责人+创建人；操作者本人除外；同一活动里被提及者只收 mention 通知。
- 截止日期提醒：项目级自动化（见 14.自动化），对负责人与订阅者各发一次窗口内提醒；Completed/Cancelled 项不发。

## comments-and-activity.md（工作项评论）

- 评论支持一层线程；富文本；@提及→邮件+Inbox；表情反应；复制评论链接。
- 编辑仅作者（**管理员也不行**），显示 edited 标记；原文本保留在活动日志；删除仅作者（管理员也不能删他人评论，只能 Hide）；删除永久但活动记录保留。
- 公共/私有评论标签只在已发布项目生效：作者可 Switch to public/private comment；回复跟随父评论切换；公开板访客评论恒公开。
- 活动：系统活动（创建/状态/负责人/优先级/估算/截止日/周期模块/标签/关系）+用户活动（评论/工作日志/附件/描述编辑）；评论全程（含编辑历史）入活动日志；反应也记录。
- 提交快捷键：Enter 提交（可改为 Mod+Enter，用户级全局设置）。

## comments-moderation.md（Enterprise Grid）

- 管理员可隐藏工作项/页面/团队空间/倡议评论：选原因→横幅替代原文；作者可见自己的（标记 hidden）；所有人可 Show 临时查看；Unhide 恢复；隐藏父评论连回复一起隐藏。
- 记录：活动日志+审计日志（谁在何时隐藏及原因）。
- 公开链接上隐藏评论同样生效（显示横幅）；只有登录的工作区管理员可执行。

## subscribers.md（订阅者）

- 订阅入口：工作项 Header Subscribe/Unsubscribe；自动订阅：创建/编辑/评论/被指派/被提及（须为项目成员）；移除指派不自动退订。
- 批量订阅（Pro）：List/Table 选中+铃铛。
- 项目级订阅者（Enterprise Grid）：项目设置→Members→Project subscribers；自动订阅项目内全部现有与未来工作项；噪音大，建议配合通知偏好。
- 订阅者管理（Enterprise Grid）：订阅按钮旁成员选择器，需编辑权限，仅工作区成员可被加入。
- Your Work→Subscribed 标签查看全部订阅项。

## project-updates.md（项目更新，Pro）

- 项目设置 Features→Project Updates 开启（项目 Admin）；Overview 侧栏 Updates 标签。
- 状态三档：On track / At risk / Off track；更新时快照项目进度 {completed}/{total} 与百分比。
- 发帖：Admin/Contributor；Commenter/Guest 只读+反应；评论 Admin/Contributor 可发，Contributor 只能编辑删除自己的。
- 汇总：项目在倡议中时，倡议统计各项目最新更新状态。
