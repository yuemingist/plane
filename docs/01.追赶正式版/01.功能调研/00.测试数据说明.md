## 造数方式

- 通过 `docker exec plane-api-1 bash -c "python manage.py shell < /tmp/seed.py"`，用 Django ORM 直接造数（脚本保存在本机 `/tmp/plane-seed/seed.py`，未入库）。
- `Issue.save()` 会自动维护 `sequence_id`（IssueSequence）与 `sort_order`，无需手工处理。
- 注意点：`IssueLabel / IssueAssignee / IssueSubscriber / CycleIssue / ModuleIssue / IssueRelation / ModuleMember / EstimatePoint` 等中间表都是 `ProjectBaseModel`，`project_id` 非空，必须显式传 `project`（不能只走 M2M `.add()`）。
- 造数脚本幂等（大量使用 get_or_create），可安全重跑；早期一次失败运行曾重复创建评论，已清理（保留每个 (issue, 文本, actor) 最早一条）。
