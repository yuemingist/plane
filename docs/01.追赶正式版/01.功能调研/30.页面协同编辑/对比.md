# 页面协同编辑 对比（实测日期 2026-11-14）

> 环境：云端 app.plane.so（business trial，工作区 yueming，项目 GZRC）；CE 本机 `http://yuemingmac-mini.tail43aa97.ts.net:3000`（demo-workspace，项目 WEB）。
> 说明：只有单一账号，实时协同的多用户光标无法两账号实测，改为记录 UI 上存在的协同指示元素。

## 页面结构对比（云端 vs CE）

### Pages 列表页

| 结构         | 云端                                                   | CE                                          |
| ------------ | ------------------------------------------------------ | ------------------------------------------- |
| 顶部操作     | Add page（右上深蓝按钮）                               | Add page（同样式）                          |
| Tab          | Public / Private / Archives                            | Public / Private / **Archived**（措辞不同） |
| 排序/筛选    | Date modified + 筛选                                   | Date modified + 筛选（一致）                |
| 列表行内操作 | 创建人头像、收藏、更多                                 | 创建人头像、添加到收藏、更多（一致）        |

## 待验证问题闭环（U7 等）

**U7：CE 无 LLM key 时 AI 菜单的降级表现 —— 结论：整体隐藏，非置灰、非报错。**

- CE 页面编辑器（打开 12 节长文实测）：
  - 正文输入 `/`：命令菜单正常弹出，条目为 Text/Heading 1-6/三种列表/Table/Quote/Code/Image/Callout/Divider/Emoji + 颜色组，**无任何 AI 项**（无 AI Block、无 Ask AI）。
  - 选中文字：浮动工具栏只有 Text/Link/Color/B/I/U/S/对齐，**无 AI 菜单项、无评论**，即 AI 菜单被完全隐藏。
  - 编辑器右上无 AI summary 按钮；头部无 AI 入口。
  - 全程无报错、无置灰项；god-mode AI 分区为空（CE 未配 LLM key）时编辑器就是"纯编辑器"。
- 云端 AI 菜单全集（实测记录）：
  - 编辑器右上 **AI summary**（AI 生成整页摘要，可重新生成/删除，标注 Powered by Plane AI）。
  - / 菜单 Advanced 组的 **AI Block**。
  - 全局顶栏 **AI assistant** 按钮 + 侧边栏 **AI**（/yueming/ai-chat/ Ask Plane AI 独立页）+ 首页 "Ask Plane AI" 输入区。
  - 选中文字浮动工具栏：本次未看到显式 "Ask AI/改进措辞/翻译" 子菜单；选区工具栏的 AI 触发不在此处（或需更大选区/右键）；实测确认的 AI 入口为上述三处 + 选中转工作项。
  - 云端 slash 菜单本身未出现 "Ask AI / Improve wording / Translate" 等文本菜单项——如后续要追赶，以 AI summary + AI Block + 全局 AI 助手为基线。

**其它实测结论**

- CE 页面可正常编辑（长文写入 "U7 实测：CE 可正常编辑" 成功），编辑链路健康。
- CE 编辑器加载时短暂出现 "正在加载版本详情 / 仅查看 / 恢复" 横幅，加载完成后消失，属加载态闪现（疑似版本详情接口慢），可留意。
- 云端页面创建的测试数据：GZRC 项目下新增页面"协作测试页 CollabTest"与工作项 GZRC-4（选区转工作项实测产物）；未点发布确认、未删改任何既有数据。
