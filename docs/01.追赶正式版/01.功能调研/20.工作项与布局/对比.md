## 待验证问题闭环

- **U1（epic 布局/入口）**：云端与 CE 均无独立 Epic 布局或侧栏入口；Epic 表现为 Issue Type（is_epic）。云端类型贯穿更好（行 chip、详情 chip、类型切换、Type/Parent type 筛选）；CE 仅图标级体现。结论：**两版均无 epic 专属布局；差距在类型体系的入口深度（见 D-03）**。
- **U4（多选 bulk）**：云端多选后出现完整批量工具栏（编辑/复制/归档/删除/批量设属性），无升级提示；CE 选中后仅渲染升级 Banner（源码证据 `IssueBulkOperationsRoot` + i18n key `bulk_operations.upgrade_banner.*`）。**结论：U4 成立——CE 批量操作只有升级 banner，云端是完整功能**。（CE UI 多选触发受自动化限制未能截图，改用源码证据闭环。）
- **U11（甘特/时间线依赖箭头）**：云端时间线在 blocked_by 存在时渲染蓝色依赖箭头（GZRC-1→GZRC-2，见 cloud-work-items-timeline-deps 截图）；CE 时间线对 WEB-7←WEB-4 的 blocked_by 关系**不渲染任何箭头**（见 ce-work-items-timeline-deps 截图，两 bar 相邻无连线）。**结论：U11 成立——CE 缺依赖箭头渲染**。
