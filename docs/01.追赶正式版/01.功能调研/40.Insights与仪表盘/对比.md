# Insights 与仪表盘 对比（实测日期 2026-11-14）

> 云端：app.plane.so（yueming 工作区，Business trial）；CE：http://yuemingmac-mini.tail43aa97.ts.net:3000（demo-workspace）
> 云端语言为中文（账号语言设置为中文），CE 同为中文界面。

### 云端独有的辅助形态

- 创建 dashboard 弹窗内置 **Basic/PQL 筛选**（PQL tab + 自然语言描述输入框 "Describe your filter in plain language..."，应用按钮）——即 dashboard 数据源也接 AI/自然语言筛选。
- Dashboard 名称占位符示例："跨项目容量"、"按团队工作量"、"跨所有项目状态"。

## 待验证问题闭环

- **U10（CE 固定图表页 vs 云端可配置 dashboard，widget 差异清单）**：已实测闭环。CE 工作区级只有固定 Analytics 页（概览+工作项 2 个 tab，图表类型：KPI 数字、折线（创建 vs 解决）、雷达图（概览）、透视表+CSV 导出），**无任何 dashboard 概念**。云端为「固定 Analytics 页（7 tab）+ 可配置 Dashboards（26 种 widget）」双层结构，且 dashboard 支持分享/发布/导出、数据源绑定多项目、Basic/PQL 筛选。追赶立项建议：先做 dashboard 框架 + 高频 widget（数字/柱状/线形/饼形/工作项表格），周期与 Intake 类 widget 二期。
- 云端项目级/工作区级其它报表入口：项目级仅有「分析」滑出面板（与 CE 同构）；工作区级另有 Dashboards 页与首页 widget（管理小部件）。未发现其它报表入口。
