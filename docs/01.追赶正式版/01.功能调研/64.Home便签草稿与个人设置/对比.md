# 64. Home 便签草稿与个人设置 对比（实测日期 2026-11-14）

> 云端：YM Research（slug=thinkym，Business 试用至 2026-11-28）/ 测试数据：便签「调研-测试便签：追赶项目备忘」、草稿「调研-草稿工作项测试」（SURVEY 项目）
> CE：demo-workspace / 测试数据：草稿「调研-CE侧草稿验证」（DSGN 项目）
> 工具说明：IAB 截图面故障（延续批次 3/4），全程使用本机 Chrome + CDP（puppeteer-core，/tmp/plane-chrome-tools）驱动与截图。
> **重要纠偏（对本批任务简报的修正）**：本仓库 CE fork（v1.5.0）**已经内置完整的 Stickies（便签）、工作区草稿（Drafts）、个人设置、快捷键面板**，且实测功能可用——任务简报中「CE 无便签/草稿实体」的预期不成立（代码+实测双重证据见第 6 节）。CE 真正缺的是：项目 Overview 页、个人设置中的三个偏好项、首页 AI 卡、快捷键面板的商业版分组。
