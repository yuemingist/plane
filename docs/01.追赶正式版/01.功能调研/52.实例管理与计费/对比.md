# 实例管理与计费 对比（实测日期 2026-11-14）

> 云端：app.plane.so/thinkym → 设置 → 账单与计划（Business 试用，昨日已有 1 张 bill 页 HTML，本次补全各区块与套餐矩阵）。
> CE：god-mode 实例管理台 http://yuemingmac-mini.tail43aa97.ts.net:3001/god-mode/（同账号 yueming@yuegr.com 登录），逐 tab 盘点。
> 结论速览：云端账单页=完整商业化控制台（当前 plan 卡/席位用量/订阅/付款方式/发票历史/三档套餐矩阵）；CE 完全没有计费（billing 页只显示 Community），其对位是 **god-mode 实例管理台**（6 分区 35 配置项）；两者是不同层的东西——云端是"客户视角的订阅自服务"，god-mode 是"自托管管理员的实例配置"，CE 缺的是前者。

### CE web 侧计费页

- /settings/billing/ 只显示 **Community** 标识（无套餐卡、无席位、无发票、无升级入口）；侧边栏底部「Community」按钮只是打开付费计划宣传模态框（无支付流程）。

## 待验证问题闭环

- **云端有无 instance admin 入口？** 已闭环：客户侧没有（多租户托管），实例级配置能力是 CE/god-mode 独有；云端对位物=账单门户（Stripe 外部门户，未进入以避免触发付费流程）。
- **god-mode 是否仍是 6 分区 35 配置项？** 已闭环：与 11.盘点一致——General/Email/Authentication/Workspaces/AI/Images，字段集吻合（详见上表）。
